# 새 주인공 도트 — 규격과 팔레트

게임: 한국 시골 농사 시뮬 「리틀 루트」. 스타듀밸리풍 탑다운, 귀엽고 예쁜 치비.

## 캔버스
- PNG **128 x 192**, 배경 투명(알파 0)
- **발바닥이 190행**에 닿는다 (189~191 안). 캐릭터 키는 **184px 안팎**
- 가로 한가운데 x=64. 내용은 0~127 안에

## 그림체 — 귀엽고 예쁘게
- **치비**: 머리가 키의 40% 안팎(70~80px). 몸통·다리는 짧고 통통
- **눈이 크다**: 한 눈이 가로 14~20px. 검은 눈망울에 **흰 반짝이 두 점**(큰 것 + 작은 것),
  아래쪽에 밝은 홍채 반사. 위 속눈썹 선은 바깥으로 갈수록 두껍게
- 눈썹은 가늘게, 코는 점 하나, 입은 작게(웃는 선), 볼터치
- **윤곽선은 한 겹**(1px)으로 실루엣을 두른다. 안쪽 경계선도 필요한 데만
- 면은 평평하게, 그늘은 한 단만. 디더링·노이즈 금지 (도트 하나하나가 뜻이 있어야 한다)
- 실루엣이 또렷해야 한다 — 게임에서 **0.42배로 줄여** 그린다(54x81px에서도 읽혀야 한다)

## 팔레트 — 이 21색 말고는 한 칸도 쓰면 안 된다
게임이 실행 중에 옷·머리·살결 색을 이 값으로 찾아 바꿔치기한다. 한 값이라도
어긋나면 그 칸은 옷을 못 갈아입는다.

```python
PAL = {
    'O': (54, 33, 26),      # 윤곽선
    's': (243, 159, 138),   # 살결
    'S': (213, 116, 98),    # 살결 그늘
    'H': (250, 192, 170),   # 살결 밝은 면
    'e': (66, 32, 30),      # 눈망울 · 속눈썹
    'i': (136, 70, 42),     # 홍채 반사 · 눈썹
    'w': (246, 242, 234),   # 눈 반짝이
    'r': (235, 128, 114),   # 볼터치
    'm': (170, 84, 66),     # 입
    'b': (58, 88, 168),     # 윗도리
    'B': (38, 58, 120),     # 윗도리 그늘
    'L': (94, 126, 200),    # 윗도리 밝은 면
    'p': (134, 88, 46),     # 아랫도리(바지/치마)
    'P': (98, 62, 32),      # 아랫도리 그늘
    'q': (158, 108, 58),    # 아랫도리 밝은 면
    'h': (118, 72, 40),     # 머리카락
    'j': (152, 100, 56),    # 머리카락 밝은 면
    'g': (86, 52, 30),      # 머리카락 그늘
    'k': (82, 53, 33),      # 신발
    'n': (68, 44, 29),      # 먼 쪽 신발
    'K': (56, 37, 25),      # 신발 그늘(밑창)
}
```
- 윗도리 세 칸(b/B/L)은 **한 벌의 옷**이다. 조끼·앞치마처럼 겹쳐 입은 것으로
  보이게 하려면 밝은 칸과 어두운 칸으로 면을 나눠 쓴다
- 아랫도리 세 칸(p/P/q)은 바지든 치마든 같은 슬롯이다
- 살결은 s/S/H 셋뿐 — 손·발·얼굴 전부 이 셋으로

## 만들 것
파이썬 한 파일(Pillow)로 **정면 서기**와 **옆모습 서기** 두 장을 그린다.
문자 격자로 그린 뒤 팔레트로 바꿔 저장하는 방식을 권한다 (한 칸이 한 도트).

옆모습은 **오른쪽을 본다** (게임이 왼쪽은 뒤집어 쓴다).

## 하면 안 되는 것
- 팔레트 밖의 색
- 안티에일리어싱, 반투명(알파는 0 아니면 255)
- 이미지 확대/축소(리샘플링) — 도트를 직접 찍는다
