# 주인공 도트 새로 그리기 — 규격서

## 0. 왜 다시 그리나
지금 주인공은 32 x 48 칸을 네 배로 키운 것이다. 그런데 **세계 배경은
house.png 가 512 x 552, barn.png 가 448 x 352** 로 촘촘하다. 배경과 캐릭터의
디테일 밀도가 네 배 차이가 나서, 캐릭터만 저해상도 장난감처럼 보인다.
사용자의 지적 「그래픽 퀄리티가 너무 낮다」의 정체가 이것이다.

## 1. 반드시 지킬 것 (어기면 게임에 못 넣는다)
- 결과물은 **128 x 192 RGBA PNG**.
- 발바닥이 **y = 190 줄**에 닿아야 한다 (191 이 아니다). 캐릭터는 x = 64 를
  중심으로 좌우 대칭 위치에 놓는다.
- 게임은 이 그림을 **scale 0.5 · 카메라 zoom 0.56** 으로 그린다. 즉 화면에서는
  약 **36 x 54 픽셀**이 된다. 이 크기에서 실루엣과 표정이 읽혀야 한다.
- 텍스처 필터는 nearest 다. 반투명 픽셀은 쓰지 말 것 (알파는 0 또는 255).
- 색은 아래 표의 값을 **정확히** 써야 한다. 게임이 픽셀 단위 색 치환으로
  머리색·옷색을 갈아입히기 때문에, 표에 없는 색은 절대 안 바뀐다.

## 3. 화풍 — 사용자가 준 참고 그림
데몬슬레이어 탄지로 치비 도트. 특징:
- **면마다 색이 하나.** 그라데이션이 거의 없다
- **윤곽이 굵고 새까맣다.** 바깥 둘레뿐 아니라 **팔과 몸통 사이, 두 다리
  사이**에도 까만 줄이 들어간다. 형태를 읽게 하는 건 이 줄이다
- **머리가 키의 절반 가까이** 되는 치비 비율
- 눈은 단순한 검은 사각, 볼은 납작한 분홍 사각, 코는 없다
- **대비가 세다** — 검정·흰색·채도 높은 색이 부딪힌다
- 머리카락 실루엣에 개성이 있다 (뾰족뾰족, 좌우 비대칭)

사용자는 이 **분위기**를 원하지만, 우리가 만든 32 x 48 판을 보고
「퀄리티가 낮다」고 했다. 즉 **플랫한 색·굵은 윤곽·치비 비율은 유지하되,
해상도와 마감을 크게 올려야 한다.**

## 4. 지금까지 실패한 방식 (같은 실수를 반복하지 말 것)
- 고해상도 부드러운 명암 → 「자로 그은 티」가 나고 참고 그림과 딴판
- 32 x 48 x4배 → 배경과 밀도가 안 맞아 장난감 같다
- 눈이 얼굴 폭의 절반 → 못생긴다. 참고 그림은 얼굴 폭의 1/4 이다
- 반폭을 정수로 적어 실루엣이 한 줄에 두 칸씩 튐 → 계단으로 보인다
- 어깨가 없다가 갑자기 최대 폭 → 90도로 꺾여 상자 같다
- 바둑판 디더 → 그물·바느질 자국으로 보인다
- 채도를 너무 눌러 갈색이 카키(국방색)가 됨
- 머리 하이라이트를 네모로 칠함 → 딱지 붙인 것처럼 보인다
- 옆머리를 「두께」로 적어 얼굴이 좁아지는 줄에서 머리가 안쪽으로 딸려 들어감
- 떠 있는 머리 조각 (몸과 안 붙은 픽셀 덩어리)

## 5. 만들 것
파이썬 파일 하나가 PNG 두 장을 뽑는다:
- `<키>_boy.png`  — 남자 앞모습 서 있는 자세 (idle)
- `<키>_girl.png` — 여자 앞모습 서 있는 자세
둘은 **한눈에 남녀가 구분**되어야 한다 (머리 길이·옷차림·실루엣으로).
농사 시뮬레이션 게임의 주인공이다 (평상복, 소박하되 귀엽게).
