# 리틀 루트 주인공 도트 — 192 x 288 사양

## 만들 것
파이썬 생성기 하나. 실행하면 PNG **여섯 장**을 쓴다.

    <PREFIX>_boy_down.png   <PREFIX>_boy_side.png   <PREFIX>_boy_up.png
    <PREFIX>_girl_down.png  <PREFIX>_girl_side.png  <PREFIX>_girl_up.png

- `down` = 정면, `side` = **3/4 (오른쪽을 비스듬히 본다)**, `up` = 뒷모습
- 게임은 왼쪽을 볼 때 side 를 통째로 좌우 반전해 쓴다
- 남자/여자 각각 한 벌. 같은 세계의 같은 화풍이어야 한다

## 캔버스 (어기면 게임에 못 넣는다)
- 정확히 192 x 288 RGBA
- 알파는 **0 또는 255 만**. 반투명 한 픽셀도 안 된다 (안티에일리어싱 금지)
- 발바닥 맨 아랫줄이 **y = 286**
- 가로 중심이 **x = 95.5** (바운딩 박스 기준, ±0.5 허용)
- 알파 있는 픽셀이 **연결 요소 하나**. 떠 있는 조각 금지
- Pillow 만 쓴다. numpy 없음

## 팔레트 — 이 표 밖의 색은 한 픽셀도 쓰면 안 된다
게임이 `recolor_player_image()` 로 **정확한 RGB 치환**을 해서 옷·머리·살결을
갈아입힌다. 표에 없는 색은 영원히 안 갈아입혀져 겉돈다.

```python
# 살결 7단

# 머리 5단
HR, HR_L, HR_D, HR_DD, HR_LL = (118,72,40), (152,100,56), (86,52,30), (58,35,20), (195,165,140)
# 윗도리 5단
SH, SH_D, SH_L, SH_DD, SH_LL = (58,88,168), (38,58,120), (94,126,200), (27,41,84), (166,184,225)
# 아랫도리 5단
PT, PT_D, PT_L, PT_DD, PT_LL = (134,88,46), (98,62,32), (158,108,58), (69,43,22), (202,174,147)
```

## 화풍
농사 시뮬레이션 주인공. **기여운 치비**. 머리가 키의 40% 안팎.
- **윤곽은 재질마다 그 재질의 가장 어두운 단으로** 두른다. 검정 윤곽 금지 —
  검정으로 두르면 옷을 갈아입혀도 테두리만 그대로라 겉돈다.
  (살결 -> SK_DD, 머리 -> HR_DD, 윗도리 -> SH_DD, 아랫도리 -> PT_DD, 신발 -> SO_DD)
- 빛은 **왼쪽 위**에서 온다. 방향 세 장이 같은 광원을 쓴다
- 면마다 단색. 그라데이션·디더 금지
- 화면에서는 54 x 81 픽셀로 줄어든다. 멀리서도 실루엣이 읽혀야 한다

## 기여움이 나오는 곳 (이게 이 작업의 목적이다)
1. **눈이 제일 중요하다.** 얼굴 폭의 1/3씩. 홍채가 눈의 대부분을 채우고
   흰자는 좌우에만 조금. 동공, 큰 반사점(바깥 위), 작은 반사점(안쪽 아래).
   - 홍채가 눈과 같은 크기면 흰자가 빙 둘러 **유리구슬**이 된다
   - 홍채가 너무 좁으면 **감은 눈**이 된다
2. 눈썹은 짧고 평평하게. 길고 두껍게 안쪽으로 기울이면 **화난 얼굴**이 된다
3. 코는 두어 칸, 입은 작게. 작을수록 어려 보인다
4. 볼 홍조는 눈 **아래**에 (눈과 같은 줄에 두면 눈에 가려진다)
5. 실루엣이 둥글어야 한다. 직각 모서리는 깎는다

## 해상도를 올렸으면 **전부** 올려야 한다
저해상도 그림을 확대해 놓고 얼굴만 다시 그리면 얼굴만 정밀하고 몸은
계단이라 따로 논다. 192칸 정밀도로 **다 같이** 그려야 한다.
- 실루엣 곡선 (머리, 어깨, 팔, 장화)
- **음영 경계** — 옷 주름, 머릿결, 소매단, 명암 면의 가장자리
- 손가락, 옷깃, 단추

## 3/4 이 정면과 달라야 한다
「정면을 옆으로 민 것」이 되면 실패다. 오른쪽을 비스듬히 본 사람은:
- 이목구비가 돌아선 쪽으로 몰린다
- **먼 눈(오른쪽)이 눌려 좁아진다.** 그 바깥 뺨은 한 칸, 가까운(왼) 쪽 뺨은 세 칸
- 코가 실루엣을 살짝 밀고 나간다
- 턱선이 먼 쪽 귀에서 가까운 쪽 턱으로 비스듬히 내려오고, 목은 턱보다 먼 쪽에 붙는다
- 어깨가 비틀린다 — 가까운 어깨가 한 줄 늦게 더 멀리 벌어진다
- 가까운 팔·손·다리가 밝고 크고 앞에, 먼 쪽은 어둡고 작고 뒤에
- 두 다리가 겹쳐 사이가 좁아진다
- 머리 덩어리는 거의 안 변한다 (30도쯤 튼 머리는 실루엣이 그대로다)

## 여자
긴 머리가 어깨를 덮는다. 3/4 에서는 먼 쪽이 길게 흐르고 가까운 쪽은
짧은 한 갈래만. 뒷모습에서는 등을 덮어 윗도리가 거의 안 보인다.
치마 + 맨다리 + 단화. 남자는 윗도리 + 바지 + 장화.

## 지금까지 실패한 것들 (반복하지 말 것)
- 띠 두께를 실루엣 따라 일정하게 두면 자로 그은 자국이 된다 → 두께를 제각각으로
- 좌우 대칭 주름은 주름이 아니라 무늬가 된다 → 높이를 어긋나게
- 머리 가닥을 정수리부터 끝까지 곧게 그으면 나뭇결이 된다 → 짧게, 적게
- 실루엣 표와 칠하는 폭이 어긋나면 다리 가장자리에 윗도리 색이 남는다
- 캔버스 밖을 「공기」로 세면 맨 아랫줄이 통째로 검은 받침대가 된다
- 얼굴 창이 실루엣 밖으로 나가는 줄에 윤곽을 박으면 뺨에 까만 딱지가 붙는다
- 그늘 띠가 두 칸인데 목덜미 머리가 두 칸뿐이면 통째로 먹혀 연필 자국이 남는다
