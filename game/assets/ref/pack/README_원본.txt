턱선·허벅지·남자 옆머리를 정리하고 소매와 신발 디테일을 다듬은 일상복 남녀 캐릭터 — 정면 각 1프레임.
각 PNG는 32×48 RGBA 투명 배경. 미리보기는 10배 확대.
남자: 짧은 갈색 머리, 푸른 맨투맨, 회색 바지, 운동화.
여자: 보라색 긴 머리, 크림 블라우스, 청록 치마, 양말과 운동화.
좌표: 왼쪽 위 (0,0), x 오른쪽, y 아래쪽.
JSON palette: HEX, 0은 투명. sprites[name].rows[y][x]는 색상 ID.
pixels와 CSV에 불투명 픽셀 좌표와 RGBA가 있습니다.
데이터로 PNG를 정확하게 복원하는지 검증했습니다.
spritesheet.png: 64×48, boy=(0,0,32,48), girl=(32,0,32,48).
실행: pip install Pillow 후 python draw_pixels.py
