# 집 꾸미기 — 가리키고 누른다 (동물의 숲식)

관련 코드: `interior_ui.gd`(`_deco_input`/`_move_cursor`/`_furn_at`/`_cancel_held`) ·
검사: 하네스 스텝 252(`DECO_OK`)

---

## 러그가 「못 옮기는 것」이었던 이유

깔려 있는 하트 러그를 옮길 수 없다는 이야기가 있었다. 코드를 보면
집는 길은 있었다 — `interact`(E)나 `use_tool`(Space)을 누르면 커서 아래
가구가 집힌다. 그런데 화면에 적힌 안내는 이랬다.

> 꾸미기 모드 — 집기·놓기 · X: 판매 · F: 완료

**무슨 키로 집는지가 한 글자도 없다.** 게다가 커서는 방향키로 12픽셀씩
밀어야 했고, 겨눈 자리에 무엇이 걸리는지도 보이지 않았다. 러그는
처음부터 집을 수 있었지만, 집는 방법이 화면 어디에도 없었다.

## 지금은 이렇게 한다

| 하고 싶은 것 | 어떻게 |
|---|---|
| 무엇이 집힐지 본다 | 가리키면 **테두리와 이름**이 뜬다 |
| 집는다 / 놓는다 | **왼쪽 클릭** (또는 E · Space) |
| 옮기는 중에 그만둔다 | **오른쪽 클릭** — 제자리로 돌아간다 |
| 산다 | 왼쪽 목록을 **클릭** (또는 숫자키) |
| 판다 | 들고 X |
| 끝낸다 | F |

들고 있는 가구는 **가리킨 자리에 서 있도록** 따라온다 — 그림의 아래
가운데(바닥에 닿은 자리)가 커서에 온다. 놓을 수 있으면 초록, 안 되면
빨강으로 비친다. 방향키로도 그대로 되고, 방향키를 쓰면 마우스 겨눔은
놓는다 (둘이 서로 싸우지 않게).

## 마우스가 안 먹던 진짜 이유

`interior_ui`의 배경과 캔버스는 `Control`이다. Control의 기본
`mouse_filter`는 **STOP** — 클릭이 거기서 먹혀 `_unhandled_input`까지
오지 않는다. 둘 다 `IGNORE`로 돌려 마우스가 통과하게 했다.
(위쪽 「연구노트·퀘스트」 단추는 그대로 눌린다 — 그건 진짜 Button이다)

## 검사 (`DECO_OK`)

러그 하나만 놓고 네 갈래를 본다 — **가리킴**(`_furn_at`이 러그를 집어낸다) ·
**집힘**(`_pick_up` 뒤 손에 들려 있다) · **옮김**(다른 자리에 놓으면 좌표가
실제로 바뀐다) · **취소**(오른쪽 클릭이 제자리로 되돌린다).
