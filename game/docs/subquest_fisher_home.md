# 서브 퀘스트 「용식의 부탁 — 살 집 한 채」 + 수납 상자

낚시꾼 용식이 이 마을에 눌러앉고 싶어 집을 부탁하는 이야기.
보상으로 **수납 상자** 제작 레시피가 열린다.

관련 코드: `game_data.gd`(데이터·조건) · `story.gd`(대사·진행) ·
`village_ui.gd`(대화 라우팅·설치) · `interact.gd`(집터 선택지) ·
`npcs.gd`(분수대 배치) · `storage_ui.gd`(상자 창) · `interior_ui.gd`(집 안 상자)

---

## 0. NPC 이름

| id | 역할 | 이름 |
|----|------|------|
| `merchant` | 마을 잡화점 상인 | **만수** |
| `fisher` | 낚시꾼 | **용식** |

`GameData.NPCS`의 `name` 값이며, 모든 대사·안내 문구도 이 이름으로 통일했다.

## 1. 시스템 흐름도

```
[바닷길 개방]  fisher_quest = "done" · sea_open = true
      │        world_gen._reveal_sea() 가 sea_open_day = 오늘 을 기록
      │
      ▼  (정확히 3일 뒤 — day >= sea_open_day + FISHER_HOME_DAYS(3))
┌─────────────────────────────────────────────────────────┐
│ story._fisher_home_update()  ← main._process 가 매 프레임 확인 │
│   fisher_home: ""  →  "wait"        토스트: 「용식이 분수대 앞에 서 있다」│
└─────────────────────────────────────────────────────────┘
      │
      │  npcs.npc_place_now("fisher") → "fountain"
      │  npc_place_tile → 분수대(FOUNTAIN) 남쪽 한 칸  ※ 하루 종일 그 자리
      ▼
[플레이어가 다가가 E]  village_ui._talk_to(fisher)
      │
      ▼
┌── story.fisher_home_greet() ─────────────────────────────┐
│  안내창: "용식이 분수대 물끄러미 바라보며 서 있다…"          │
│   [대화하기]        → _start_fisher_home_dialog()          │
│   [나중에]          → 닫기 (fisher_home 은 "wait" 그대로)    │
└─────────────────────────────────────────────────────────┘
      │  ※ 말을 거는 것만으로는 퀘스트가 시작되지 않는다
      ▼  [대화하기] 를 고른 경우에만
[부탁 대사 7페이지] → _end_fisher_home_ask()
      fisher_home: "wait" → "build"      퀘스트 창(Q)에 서브 퀘스트 등장
      │
      ▼
[집터 놓기]  가방의 「집터」(housing_kit) → story.try_place_home_plot()
      │        마을 안이든 밖이든 트인 풀밭이면 어디든 가능
      ▼
[집터 팻말 E]  interact.gd → 빈 집터 안내창
      │   fisher_home == "build" 일 때만 선택지가 하나 더 붙는다
      │   [집을 짓는다 (용식의 집)] → story.build_fisher_home(door)
      ▼
┌── build_fisher_home() ───────────────────────────────────┐
│  집터 팻말 제거 → _fill_building() → 집 노드 생성           │
│  settler_homes["fisher"] = 그 자리  (이제 용식의 거처)      │
│  fisher_home: "build" → "built"    ← 건설 완료 = 조건 달성   │
└─────────────────────────────────────────────────────────┘
      │  NPC 머리 위 마크: ❗ → ❓
      ▼
[다시 용식에게 E]  story.fisher_home_report()
      │
      ▼
[완료 대사 6페이지] → _end_fisher_home_reward()
      fisher_home: "built" → "done"
      ★ recipes_unlocked 에 "storage_box" 추가 (즉시 습득)
      ★ 용식 호감도 +15
```

### 상태값 요약 (`GameData.fisher_home`)

| 값 | 뜻 | 다음으로 가는 조건 |
|----|----|------------------|
| `""` | 아직 | 바닷길 개방 + 3일 경과 |
| `wait` | 분수대 앞에서 기다린다 | 「대화하기」를 고른다 |
| `build` | 집터를 놓고 집을 짓는다 | 집터 위에 집 건설 |
| `built` | 집 완성 — 알리러 가기 | 용식에게 말 걸기 |
| `done` | 완료 | — |

## 2. 대화 스크립트

### 2-1. 첫 상호작용 (선택지 창)

> **용식**
> 용식이 분수대 물끄러미 바라보며 서 있다.
> 무슨 할 말이 있는 얼굴이다.
>
> `[대화하기]` `[나중에]`

### 2-2. 부탁 (「대화하기」를 고른 뒤)

> **용식**
> 「어, 마침 잘 왔네. 자네를 기다렸어.」
>
> 「사흘 내리 이 마을 물에서 낚싯대를 담가 봤거든.
> ...참 이상하지. 고기가 잘 물려서가 아니야.」
>
> 「아침엔 물안개가 곱게 깔리고, 낮엔 애들이
> 분수에서 첨벙거리고, 저녁이면 누가 꼭
> 『밥은 먹었나』 하고 묻는다니까.」  *(웃는 얼굴)*
>
> 「나야 평생 물 따라 떠돌던 사람인데 말이야,
> 여기서는 자꾸 짐을 풀고 싶어지더군.」
>
> 「그래서 부탁이 하나 있네.
> 내가 눌러앉을 집을 한 채 지어 줄 수 있겠나?」
>
> 「자리는 자네가 정해 주게. 마을 안이면 어디든 좋아.
> 빈 집터를 놓고, 그 위에 집을 올려 주면 되네.」
>
> 「집이 다 되면 다시 찾아와 주게.
> ...빈손으로 부탁만 하진 않을 테니.」

안내: *빈 집터(잡화점 레시피)를 마을 아무 곳에나 놓고, 집터 앞에서 E를 눌러 집을 올리자.*

### 2-3. 집터 팻말 (건설 선택지)

> **빈 집터**
> 새 주민을 위해 마련해 둔 빈 집터다.
> 용식이 살 집을 여기에 지을까?
>
> `[집을 짓는다 (용식의 집)]` `[회수하기]` `[닫기]`

### 2-4. 완료 (집을 짓고 다시 말을 걸었을 때)

> **용식** *(웃는 얼굴)*
> 「...허, 진짜로 지어 줬네.」
>
> *(용식이 새 집 쪽을 한참 바라본다.)*
>
> 「떠돌이한테 『여기가 네 집이다』 하고 말해 주는 게
> 어떤 건지, 자네는 모를 걸세.」
>
> 「받게. 내가 배에서 쓰던 상자 도면이야.
> 목재 여덟이면 하나 짤 수 있네.」
>
> 「집 안에 놓고 뭐든 넣어 두게. 가방이 터질 것 같을 때
> 한 짐 덜어 두면 그렇게 편할 수가 없어.」
>
> 「이제 나도 이 마을 사람일세.
> ...아침에 물가에 나오면 인사나 하자고.」

보상 안내: *수납 상자 레시피를 배웠다! 집 안 책상(제작대)에서 목재 8개로 만들 수 있다.*

## 3. 수납 상자

| 항목 | 값 |
|------|-----|
| 제작 | 집 안 **책상(제작대)** · **목재 8** (`DESK_RECIPES.storage_box`) |
| 해금 | 용식의 부탁 완료 시 `recipes_unlocked` 에 추가 (상점 판매 없음) |
| 설치 | 가방 「배치」 탭에서 클릭 → **집 안에서만** 세간으로 놓인다 |
| 사용 | 상자 곁에서 **E** → 수납 상자 창 (가방 ↔ 상자) |
| 용량 | 아이템 **종류 40칸** (`STORAGE_SLOTS`) · 같은 종류는 개수 제한 없음 |
| 저장 | `GameData.storage_stock` (아이템 id → 개수), 세이브에 그대로 실린다 |

- 상자를 여러 개 놓아도 **안은 하나로 이어져 있다** — 어느 상자를 열든
  같은 살림이 보인다. 어디에 뭘 넣었는지 외우게 만들지 않기 위해서다.
- 집터·편지·할아버지의 씨앗처럼 **넣으면 곤란한 물건은 목록에 오르지 않는다**
  (`storage_can_store`).
- 꾸미기(F)로 자리를 옮길 수 있고, 오두막(집 1단계)에는 놓을 자리가 없다.

### 창 조작

```
┌ 수납 상자 (3/40칸 · E/ESC: 닫기) ──────────────┐
│  가방                    │  상자                │
│  목재 x120   [1] [전부]  │  광석 x40  [1] [전부] │
│  광석 x12    [1] [전부]  │  ...                 │
└───────────────────────────────────────────────┘
```

`[1]` 은 하나, `[전부]` 는 그 칸을 통째로 옮긴다.
넣고 빼는 규칙 자체는 `GameData.storage_put/storage_take` 가 쥐고 있고,
`storage_ui.gd` 는 그것을 보여 주고 눌러 주는 창일 뿐이다.

## 4. 검증 (`dev_harness.gd` 스텝 286 · `SUBFISH_OK`)

- 이름 — 만수 · 용식
- 바닷길 개방 당일·이틀 뒤에는 **안 나온다** / 정확히 3일 뒤에 등장
- `npc_place_now` 가 `"fountain"` 을 돌려주고 분수대 남쪽에 선다
- 말을 걸면 선택지 두 개(`대화하기`/`나중에`)가 뜨고, **그때까지 `wait` 그대로**
- 「대화하기」 → `build` · 퀘스트 창에 등장
- 집터 설치 → 집 건설 → `built` · 집 오브젝트 · `settler_homes` 등록 · ❓ 마크
- 다시 말 걸기 → `done` · `storage_box` 레시피 해금 · 완료 목록 등록
- 레시피 재료가 목재 8인지
- 수납 상자 넣기/꺼내기/비우기, 제외 품목, 40칸 제한
