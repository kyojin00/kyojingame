한 배치로 들어간 여섯 가지. 관련 코드: `story.gd`(다가오는 걸음·시선) ·

## 1. 생선구이 그림

```
원본:  game/assets/ref/src/ref_grilled_fish.png   (유저 그림 todtjsrndl)
실행:  NODE_PATH=... node game/assets/ref/cut_grilled_fish.js
결과:  game/assets/sprites/dish_grilled_fish.png  (32x32)
```

흰 배경은 **가장자리에서 흘려 지운다** — 그림 안쪽의 밝은 하이라이트는
살아남는다. 아이콘이므로 밑변을 바닥에 붙이지 않고 한가운데에 앉힌다.

## 2. 찾아오는 사람은 서 있던 자리에서 걸어온다

규칙은 하나다. **자기가 있던 곳에서 곧장 다가오고, 걷는 내내 가는 쪽을
보고, 멈추면 플레이어를 마주 본다.**

```gdscript
func _face_dir(from: Vector2, to: Vector2) -> String     # 이 자리에서 저 자리를 볼 때
func _step_toward(npc, goal, delta, speed, reach) -> bool  # 한 걸음 · 닿으면 마주 본다
```

예전에는 몇몇 연출이 그 사람을 **먼저 플레이어의 남쪽으로 옮겨 놓았다.**

```gdscript
# 예전 — 이장이 마을 북쪽에 있었어도 늘 아래에서 위로 올라왔다
chief.position = m.player.position + Vector2(-24.0, 150.0)
```

지금은 아주 멀리 있을 때만(420px 넘게) 그 사람이 **있던 쪽**의 곁 칸으로
당겨 온다 — 방향은 그대로 지킨다. 걸음을 멈추는 자리도 「자기가 오던 쪽에서
한 발 앞」(`_visit_stop_at`)이라, 북쪽에서 온 사람은 북쪽에 선다.

도착 시선도 `dir = "up"` 고정이 아니다. 플레이어와의 상대 위치로 고른다.

## 3. 들판이 흔해졌다 — 그리고 비 오는 날은 더

```
채집물 상한:   12 →  90       (여느 날)
              26 → 130       (안개 — 발밑이 잘 보인다)
               —  → 190       (비·폭풍 — 젖은 땅이 풀을 부른다)
잡초 상한:     70 → 220
아침 잡초:      3 →   9포기   (비 오는 날은 18)
```

224x120칸짜리 세계에서 채집물 열두 개는 **없는 것과 같다.** 반나절을
걸어도 산딸기 한 포기 못 보는 게 정상이었다.

네 가지를 함께 고쳤다.

1. **세계를 지을 때부터 들판에 깔린다.** 예전에는 한 포기도 두지 않아
   새 농장의 첫날이 텅 빈 들판이었다 (`_build_map`이 `_respawn_forage(false)`).
2. **아침마다 상한까지 채운다.** 예전에는 하루 여덟 번만 자리를 찔러 봐서,
   상한을 올려도 며칠이 걸렸다.
3. **절반은 사람이 다니는 데 가까이** 뽑는다(`_forage_spot`). 세계 전체에
   고루 뿌리면 정작 지나다니는 길에서는 아무것도 못 본다.
4. **간격은 한 칸이면 된다.** 나무 간격(네 칸)을 그대로 쓰던 탓에 온
   들판이 「자리 없음」이었다. 풀 한 포기는 길을 막지 않는다.

**비 오는 날은 아침만이 아니다.** 게임 시간 25분마다 몇 포기씩 더 돋는다
(`main._process` → `_tick_rain_forage`). 비를 맞으며 걷다 보면 방금 지나온
풀밭에도 새로 돋아 있다 — 「비 오는 날은 나가서 줍는 날」이 된다.

> 자리 검사는 나무·돌과 **같은 것**을 쓴다(`_respawn_ok`). 낚시터 어귀·
> 온실 터·문 앞·바닷길 길목은 한 군데서 비워 둔다. 처음에 이 검사를
> 따로 두었다가, 상한을 올리자마자 낚시터로 내려가는 길이 산딸기로 막혔다.
> **아직 이야기가 닿지 않은 땅에는 돋지 않는다** — 가지도 못하는 곳에
> 상한을 채우면 정작 다닐 수 있는 들판이 텅 빈다.

## 4. 울타리 레시피 — 목재를 가진 손님에게만

울타리는 첫 수확과 함께 그냥 열리던 도구였다. 이제 **잡화점의 레시피**다.

```gdscript
"fence": {"name": "울타리", "cost": {"wood": 1},
    "kind": "tool", "tool": "fence", "locked": true, "shop": "잡화점"}
```

- 선반에 오르는 조건: **가방에 목재가 한 개라도 있을 것** (250G)
- 배우는 순간 도구가 열린다 (`give_recipe` → 가방에서 「배우기」)
- 나무 한 그루 베어 본 적 없는 사람에게 울타리부터 쥐여 줄 이유가 없다

## 5. 아직 못 가는 땅은 검정 무지

```gdscript
const FOG := Color(0, 0, 0)      # 지도 · 미니맵 공통
```

뭉게뭉게한 먹구름을 없앴다. 배율을 바꾸면 동그라미가 커졌다 작아졌다
겉돌아, **가려진 것이 아니라 위에 뭘 얹어 놓은** 것처럼 보였기 때문이다.
지금은 한 점 비치지 않는 검정 한 색이다.

지도가 검게 덮는 땅은 두 가지다.

| | 어떻게 열리는가 |
|---|---|
| 아직 안 가 본 곳 | 걸어서 탐사한다 (`explored`) |
| 아직 못 가는 곳 | 잠긴 확장 구역 · 이야기가 닿지 않은 야생 지역 |

**통행 차단은 사람과 짐승을 가리지 않는다.** 플레이어·NPC·동물이 모두
같은 문(`main.is_passable` → `_tile_accessible`)을 지난다 — NPC의 길찾기
(`_tile_path`)와 배회(`_pick_target`)도 그 문이다. 밤 몬스터도 이제
**걸어 다닐 수 있는 자리에서만** 기어 나온다(예전에는 플레이어 둘레
아무 곳에서나 나와, 잠긴 구역 너머에서 벽에 붙어 버렸다).

> **미탐사와 미해금은 다르다.** 검게 보이는 것은 같지만, 아직 안 가 본
> 땅까지 막아 버리면 **탐험 자체가 불가능해진다** — 못 가서 못 보고, 못
> 봐서 못 가는 자물쇠가 된다. 그래서 출입을 정하는 것은 언제나
> **해금**이고, 탐사는 지도에 드러나는 문제로만 남는다.

## 6. Q창에서 계절 축제를 뺐다

Q창의 정보 항목에서 「계절 축제」를 없앴다(목록·상세 모두). 미니 트래커의
축제 줄도 함께 뺐다 — 미니창에서 「계절 축제」를 보고 Q를 열면 그 자리가
비어 헛걸음이 되기 때문이다. **축제 자체는 그대로다** (이장과의 축제
이야기·달력·기록은 손대지 않았다). Q창은 「지금 할 일」만 담는다.

## 검증 (`dev_harness.gd` 스텝 234 · `LIVELY_OK`)

- 생선구이가 32x32로 실려 있다
- `_face_dir`이 네 방향을 바르게 고른다
- 이장을 플레이어 **북쪽**에 세워 두고 연출을 걸면 북쪽에 그대로 있고,
  내려다보며(`down`) 걸어온다 — 남쪽으로 옮겨지지 않는다
- 채집 상한이 맑음 90 이상 · 비가 그보다 크고, 세계에 서른 포기 이상 있다
- 빗속 한 틱에 실제로 더 돋는다
- 울타리가 튜토리얼 자동 해금에서 빠졌고, 레시피를 배우면 도구가 열린다
- 지도·미니맵의 가림색이 순검정이고 불투명이다
- 깊은 숲을 잠그면 플레이어가 못 가고, 지도에 안 뜨고,
  **NPC의 길찾기도 그 땅을 지나가지 않는다**
- Q창 목록에 계절 축제 항목이 없다
