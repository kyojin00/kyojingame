# 집터 재료 · 더딘 성장 · 문구 정리 · 바닷길 막힘

한 배치로 들어간 여덟 가지. 관련 코드: `game_data.gd`(집터·경험치·레벨업 큐) ·
`tool_use.gd`(채집 문구·길목 바위) · `dialog_ui.gd`(대사 부호) ·
`hud.gd`(제작 문구) · `fishing.gd`(낚시 문구) · `day_cycle.gd`(잠자리 결산) ·
`world_gen.gd`(길목 비우기·리젠 제외) · `dev_harness.gd` 스텝 394(`BALANCE_OK`)

---

## 1. 집터는 초반 재료만으로

```
예전:  목재 60 · 석재 40 · 못 4
지금:  목재 90 · 석재 70
```

못이 문제였다. **못은 대장간에서만 파는데 대장간은 메인 스토리 7에서야
선다.** 그런데 집터가 필요한 이사 이야기는 스토리 3이다 — 재료가 없어
아예 만들 수 없는 구간이 있었다. 못을 빼고, 대신 도끼와 곡괭이만 있으면
모을 수 있는 목재·석재를 늘렸다. 양은 많지만 **길이 막히지는 않는다.**

4장 서브퀘의 사례도 못 6개 → 목재 40 · 석재 30으로 바꿨다.

## 2. 성장은 아주 더디게, 소식은 잠자리에서

```gdscript
# 예전:  30 + 20 * lv²      (Lv2까지 50, Lv5까지 530)
func skill_xp_needed(lv: int) -> float:
	return 120.0 + 85.0 * lv * lv      # Lv2까지 205, Lv5까지 2410
```

곡선을 네 배 가까이 세웠다. 한 분야를 끝까지 갈고닦는 일이 며칠이 아니라
여러 계절에 걸친 일이 된다.

**레벨업은 그 자리에서 알리지 않는다.** 올랐다는 사실만
`GameData.levelup_pending`에 쌓아 두고, 하루를 마치고 잠들면 아침 결산
화면에 한 줄로 실린다.

> 오늘 실력이 늘었다 — 벌목 Lv.3 · 채광 Lv.2

일하는 도중에 창이 튀어나오지 않고, 하루가 끝날 때 「오늘 뭘 했나」를
돌아보는 자리에서 함께 읽힌다.

## 3. 채집 문구 — 개수를 지웠다

| 예전 | 지금 |
|------|------|
| 나무를 베었다! 목재 +3 | **목재를 얻었다!** |
| 돌을 캤다! 석재 +2 | **석재를 얻었다!** |
| 커다란 바위를 캐냈다! 돌 +5 | **석재를 얻었다!** |
| 돌을 내리쳤다. (1/2) | 돌을 내리쳤다. |

몇 개가 들어왔는지는 가방이 알려 준다. 화면에 뜨는 말은 짧을수록 좋다.

## 4. 사람이 하는 말에는 부호가 넷뿐

**마침표 · 쉼표 · 물음표 · 느낌표.** 그 밖의 것은 전부 걷어낸다 —
따옴표 「」『』, 줄표, 가운뎃점, 말줄임표, ★♥ 같은 그림 기호까지.
누가 하는 말인지는 창의 이름패가 알려 주므로 따옴표도 필요 없다.

`dialog_ui._only_basic_punct()`가 한글·숫자·알파벳·공백과 저 넷만 남긴다.
**괄호 지문을 떼어낸 뒤**에 적용되고, 지문만 있는 연출 페이지(괄호로 시작하는
서술)는 손대지 않는다.

```
지금:  🔨 완성!  빗자루를 만들었다!
```

## 6. 무지개송어 그림

```
원본:  game/assets/ref/src/ref_rainbow.png   (유저 그림 anwlrothddj)
실행:  NODE_PATH=... node game/assets/ref/cut_rainbow.js
결과:  game/assets/sprites/fish_rainbow.png  (32x32)
```

## 7. 낚시는 돈을 주지 않는다

- 잡았을 때의 말에서 판매가 표기를 지웠다.
  「무지개송어를 낚았다! (85G)」 → **「무지개송어를 낚았다!」**
  괄호 안의 G가 「돈이 들어왔다」로 읽히던 것이 혼란의 절반이었다.
- 나머지 절반은 안내 보상이었다. 첫 낚시에 붙어 있던 100G를 없앴다
  (`TUTORIAL_REWARDS["fish"]`). 물고기 값은 **상점에 팔 때** 받는다.

## 8. 한 번 연 바닷길은 다시 막히지 않는다

세 겹으로 막았다.

1. `_build_sea()` — `sea_open`이면 길목(`SEA_GATE`) 칸을 **비운다.**
   예전에는 「열려 있으면 놓지 않는다」였을 뿐이라, 다른 경로로 굴러든
   바위를 걷어내지 못했다.
2. `_respawn_ok()` — 길목과 능선 줄(`SEA_RIDGE_Y`)에는 나무도 돌도
   자라지 않는다.
3. `tool_use` — 붙박이(`fixed`) 바위는 이야기가 그 자리에 오기 전까지만
   단단하다. **바닷길이 이미 열렸다면 길목 바위는 언제든 곡괭이로 캘 수
   있다.** 열린 뒤에 남은 바위가 「곡괭이가 튕겨 나온다」로 영영 길을
   막던 버그가 여기서 끝난다.

## 검증 (`dev_harness.gd` 스텝 394 · `BALANCE_OK`)

- 집터 재료에 못이 없고 목재·석재뿐이다
- 경험치 곡선이 Lv2 205 이상 · Lv4 800 이상이고, 조금 캔다고 오르지 않는다
- 레벨업이 그 자리에서 뜨지 않고 `levelup_report()`로 한 번에 나온다
- 나무를 베면 「목재를 얻었다!」 — 숫자가 한 글자도 없다
- 대사에서 「」★♥ 등이 사라지고 `. , ? !`는 남는다
- 제작 알림이 「빗자루를 만들었다!」로 나온다
- 무지개송어 그림이 32x32로 실려 있다
- 물고기를 낚아도 소지금이 그대로고, 문구에 G가 없다
- 열린 뒤 길목에 바위를 놓아도 `_build_sea()`가 걷어내고,
  남아 있어도 곡괭이 한 번에 캐지며, 리젠 후보에서도 빠진다
