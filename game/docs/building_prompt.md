# 건물 그림 주문서 (이미지 생성용)

`house.png` · `house_general.png` 두 장을 넣어 보고 남은 문제를 그대로
문장으로 옮긴 것이다. **공통 규격**을 먼저 붙이고 뒤에 **건물 한 줄**을 붙인다.

규격의 근거는 `building_art.md`에 있다. 여기 있는 문장은 전부
「안 지키면 게임에서 이렇게 깨진다」가 하나씩 붙어 있는 것들이다.

---

## 공통 규격 (매번 앞에 붙인다)

```
2D 픽셀아트 건물 한 채. 정면에서 똑바로 본 모습. 배경은 투명(알파).

【비율 — 제일 중요】
지붕 끝에서 지붕 끝까지의 가로가, 처마 그림자까지 포함한 세로와
거의 같게. 목표는 가로 10 : 세로 10이고, 가로가 세로보다 넓어지면 안 된다.
가로로 퍼진 납작한 집 말고, 세로로 시원한 집. 필요하면 이층으로 올린다.

【문】
문은 건물 정중앙, 정면을 보게. 좌우 어느 쪽으로도 치우치면 안 된다.
문 앞 계단은 두세 단까지만.

【실루엣】
울타리 · 화분 · 덤불 · 간판 같은 장식은 전부 지붕 폭 안쪽에.
지붕보다 옆으로 튀어나오면 안 된다.
굴뚝 연기는 그리지 말 것. 굴뚝 자체는 지붕 높이를 넘지 않게 짧게.
건물 밑동은 땅에 닿고, 바로 아래 얕은 바닥 그림자.

【그림체】
회벽은 노란기 없는 차가운 흰빛(#e2e2d6), 기와는 진한 주황(#ce702e),
나무 기둥은 갈색(#7a542e), 주춧돌은 회색(#b0b0a8), 창유리는 짙은 남빛(#46708c).
목조 골조(하프팀버)가 드러나는 중세 유럽 시골집. 기와는 한 장씩 보이게.
빛은 왼쪽 위에서, 처마 밑과 창턱 아래에 그림자. 등불은 따뜻하게 켜 둔다.
색 단계는 굵게 끊어서 도트처럼. 그러데이션으로 뭉개지 말 것.
윤곽에 두꺼운 검정 테두리를 두르지 말 것.
```

## 지금까지 받아 본 결과

아홉 채를 받는 데 열한 장이 들었다. 버린 두 장은 전부 **가로가 넓어서**다.

| 실루엣 비율 | 들어간 크기 | |
| --- | --- | --- |
| 1.59 : 1 | — | 안 씀 (`ref_post_wide.png`) |
| 1.53 : 1 · 1.39 : 1 | 448 x 280~292 | 다시 받음 (집·잡화점 1차) |
| 1.02 : 1 | 391 x 384 | 좋다 |
| 0.76~0.79 : 1 | 291~305 x 384 | 좋다 |
| 0.70 : 1 | 269~270 x 384 | 좋다 |
| 0.64 : 1 | 244 x 384 | 좀 좁지만 쓸 만하다 |

**가로가 남는 건 티가 안 나고, 세로가 모자라면 바로 낮아 보인다.**
0.64까지 좁아져도 나란히 놓으면 멀쩡한데 1.39만 되어도 혼자 납작하다.
목표를 「가로 10 : 세로 10」으로 적은 건 **넘기지 말라**는 뜻이지 꼭
채우라는 뜻이 아니다. 실제로 잘 나온 건 0.64~1.02 사이였다.

`ref_post_wide.png`는 같은 우체국인데 1.59 : 1인 데다 테두리 선이
굵은 다른 그림체라 안 썼다. 원본은 남겨 뒀다.

## 받은 뒤

1. `game/assets/ref/src/`에 넣는다
2. `cut_house.js`의 `JOBS`에 한 줄 — `out`은 위 표의 파일 이름(확장자 빼고),
   `door`는 **원본에서 문 한가운데 x**를 눈으로 재서 적는다
3. `node assets/ref/cut_house.js` → `godot --headless --path game --import`

## 이미 넣은 둘을 다시 그린다면

`house.png`(우리집) · `house_general.png`(잡화점)은 원본이 1.53 : 1이라
세로가 292/384밖에 안 찼다. 위 【비율】 문장만 지켜서 다시 받으면
같은 자리에서 20%쯤 커진다. 그림 자체는 손댈 데가 없다.
