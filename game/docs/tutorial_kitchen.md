# 튜토리얼 퀘스트 「먼지 속의 조리대」

요리를 어떻게 시작하는지 **안내문으로 알려 주지 않는다**. 잡화점에서
플레이어가 하는 행동이 그대로 방아쇠가 되고, 만수의 참견으로 이야기가
굴러간다. 끝나면 요리 시스템과 요리 레시피 판매가 정식으로 열린다.

관련 코드: `game_data.gd`(상태·조건) · `story.gd`(대사·진행) ·
`shop_ui.gd`(분기 A) · `shop_room.gd`(분기 B·C) · `village_ui.gd`(선물) ·
`interior_ui.gd`(청소·조리대) · `dev_harness.gd` 스텝 288(`KITCHEN_OK`)

---

## 1. 상태 데이터

```gdscript
var kitchen_quest := ""     # "" / broom / make / sweep / found / jam / done
var kitchen_branch := ""    # recipe / buy / idle  — 어떤 계기로 시작됐는가
const JAM_ID := "dish_berry_jam"   # 첫 요리 = 산딸기잼
const JAM_BERRIES := 3             # 함께 주는 산딸기
```

| 값 | 뜻 | 다음으로 가는 조건 |
|----|----|------------------|
| `""` | 아직 | 잡화점에서 분기 A·B·C 중 하나 |
| `broom` | 빗자루 레시피 사기 | 레시피를 손에 넣음(구매/습득) |
| `make` | 잡초 모아 빗자루 만들기 | 가방에 빗자루 |
| `sweep` | 집 안 먼지 쓸기 | `kitchen_found`(먼지 3회) |
| `found` | 만수에게 알리기 | 만수와 대화 |
| `jam` | 산딸기잼 만들기 | `recipes_cooked[JAM_ID] > 0` |
| `done` | 끝 | — |

**발동 가능 조건** (`kitchen_quest_ready()`)
`village_built.has("general")` (잡화점 완공) · `not kitchen_found` ·
`kitchen_quest == ""` · `story_phase == "done"` (마을 도착 후).

**요리 레시피 판매 게이트** (`cook_shop_open()`)
`kitchen_found and kitchen_quest in ["", "done"]` — 조리대를 찾았고
튜토리얼을 마쳐야 잡화점·노점의 요리 레시피를 살 수 있다.
(옛 세이브는 로드할 때 `kitchen_found`면 `done`으로 올려 준다)

진행 판정은 `story._kitchen_update()`가 매 프레임 상태를 보고 넘긴다 —
어느 경로로 빗자루를 얻든(구매·제작·치트) 걸음이 막히지 않는다.

## 2. 발동 분기 (플레이어의 상점 이용 행동)

```
                    ┌─────────────── 잡화점 (general) ───────────────┐
                    │                                               │
 [요리 레시피 클릭] │  [씨앗 등 구매 후 문으로]  │  [아무것도 안 사고 문으로]
        │           │            │              │            │
        ▼           │            ▼              │            ▼
   shop_ui          │      shop_room.try_leave()│      shop_room.try_leave()
 _on_buy_dish_recipe│      bought_this_visit=참 │      bought_this_visit=거짓
        │           │            │              │            │
   cook_shop_open() │            └──────────────┴────────────┘
     == false       │                     kitchen_quest_ready()
        │           │                           │
        ▼           │                           ▼
  분기 A "recipe"   │                  분기 B "buy" / 분기 C "idle"
  돈도 레시피도     │                  문턱에서 한 발 물러서고 대화
  오가지 않는다     │                  (시작 뒤에는 그냥 나갈 수 있다)
        └───────────┴──────────┬────────────────┘
                               ▼
                  story.start_kitchen_quest(branch)
                  KITCHEN_OPENERS[branch] + KITCHEN_COMMON
                               │
                               ▼
                    kitchen_quest = "broom"
```

- **분기 A** — 요리 레시피를 사려 한 그 순간이 방아쇠다. 구매는 성립하지
  않는다(돈·레시피 그대로). 이미 이야기가 진행 중이면 대신
  `kitchen_block_line()`이 단계에 맞는 잔소리를 한다.
- **분기 B/C** — 아랫문 문턱을 밟는 순간 `try_leave()`가 가로챈다.
  이번 방문에 **산 것이 있는지**로 첫마디가 갈린다
  (`bought_this_visit` = 입장 때 찍어 둔 `today_spent`보다 늘었는가 —
  판매는 세지 않는다).
- 한 번 시작되면 `kitchen_quest_ready()`가 거짓이라 두 번 붙잡지 않는다.

## 3. 대화 스크립트

### 3-1. 첫마디 (분기별)

**분기 A — 요리 레시피를 사려 할 때**
> 「어어, 잠깐! 그거 요리 레시피인데.」
> 「사도 지금은 못 써. 조리대가 없잖아?」

**분기 B — 뭔가 사고 나가려 할 때**
> 「그래, 살 건 다 샀고... 어이, 잠깐만.」
> 「자네 요즘 밥은 제대로 챙겨 먹고 있나?」

**분기 C — 그냥 나가려 할 때**
> 「뭘 살지 못 정했으면 그냥 가도 돼.
> ...그런데 하나만 묻자.」
> 「자네 요즘 밥은 제대로 챙겨 먹고 있나?」

### 3-2. 공통 흐름 (세 분기가 여기서 만난다)

> 「사 먹을 데도 없는 마을에서 그러다 큰일 나.
> 한 끼라도 직접 지어 먹어야지.」
>
> 「그 집, 자네 오기 전까지 한참 비어 있었잖아.
> 먼지랑 잡동사니가 산더미일 텐데.」
>
> 「그런 집엔 말이야, 부엌 살림이 그 밑에
> 그대로 묻혀 있는 경우가 많아. 조리대 같은 거.」
>
> 「일단 쓸어 봐. 빗자루부터 있어야겠지?」
>
> 「마침 빗자루 레시피가 있어. 잡초 하나면 만들어.
> 풀숲 아무 데나 뽑으면 나오는 그 잡초 말이야.」
>
> 「먼지 밑에서 뭐가 나오는지 보고 오라고.」

### 3-3. 진행 중 요리 레시피를 또 사려 하면 (`kitchen_block_line`)

| 단계 | 대사 |
|------|------|
| broom/make | 「그건 조리대를 찾고 나서 사도 늦지 않아.」 / 「빗자루부터 만들어서 집을 한번 쓸어 보라니까?」 |
| sweep | 「빗자루는 챙겼네? 그럼 집으로 가야지.」 / 「먼지더미 앞에서 쓸다 보면 뭐가 나올 거야.」 |
| found | 「조리대 찾았다며! 그 얘기부터 좀 해 봐.」 |
| jam | 「레시피는 아직 안 팔아. 준 거부터 만들어 봐.」 / 「산딸기잼. 직접 한 번 지어 보면…」 |

### 3-4. 조리대를 찾은 뒤 다시 만났을 때 (선물)

> 「찾았어? 진짜 있었지?」
> 「그 집 지은 사람이 부엌부터 들였을 거라니까.
> 먼지만 걷어내면 되는 거였어.」
> 「조리대도 찾았으니까 이것도 한번 만들어봐.
> 산딸기잼이야.」
> 「처음 해보기엔 어렵지 않을 거야.
> 재료도 같이 줄게.」
> 「직접 만들어보는 게 제일 빠르거든.」
>
> ★ 산딸기잼 레시피 x1 · 산딸기 x3 을 받았다!

계산대(E)와 마을 길에서 만나는 것 **둘 다** 이 대화로 들어간다.
머리 위에는 ❓ 마크가 뜬다.

## 4. 진행 순서와 목표 문구

```
잡화점 방문·발동 ─▶ 빗자루 레시피 구매 ─▶ 레시피 배우기 ─▶ 잡초 ×1
      ─▶ 책상에서 빗자루 제작 ─▶ 집 안 먼지 청소(3회) ─▶ 조리대 발견
      ─▶ 만수에게 알리기(선물) ─▶ 산딸기잼 제작 ─▶ 완료
```

퀘스트 창(Q)·미니 트래커에 뜨는 목표 (`kitchen_quest_objective_short`):

| 단계 | 목표 |
|------|------|
| broom | 잡화점에서 빗자루 레시피를 사자 |
| make | 가방에서 빗자루 레시피를 배우자 → 풀숲(E)에서 잡초를 1개 모으자 → 집 안 책상에서 빗자루를 만들자 |
| sweep | 집 안의 먼지와 잡동사니를 쓸어 내자 (n/3) |
| found | 만수에게 조리대를 찾았다고 알리자 |
| jam | 집 조리대에서 산딸기잼을 만들자 (산딸기 3) |

분류는 `guide`(마을 생활 안내), 보상 표기는
「요리 해금 + 산딸기잼 레시피와 산딸기 3개」.

---

## 5. 검증 (`dev_harness.gd` 스텝 288 · `KITCHEN_OK`)

- 분기 A: 레시피를 사려 하면 **돈도 레시피도 그대로**이고 퀘스트가 시작
- 분기 B: 산 것이 있는 상태로 문턱 → `branch == "buy"`, 못 나감
- 분기 C: 아무것도 안 산 상태로 문턱 → `branch == "idle"`, 못 나감
- 시작된 뒤에는 문턱에서 붙잡지 않는다 (자유 퇴장)
- 레시피 → 빗자루 → 청소 → 조리대 발견, 단계마다 목표 문구가 바뀐다
- 조리대를 찾아도 **튜토리얼 전에는 요리 레시피를 못 산다**
- 선물: 산딸기잼 레시피 1 + 산딸기 3, 상태 `jam`
- 산딸기잼을 지으면 `done` · 완료 목록 등록 · 요리 레시피 정상 구매
