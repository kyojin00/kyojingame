# 메인 스토리 2의 마지막 마디 「조리대에서 요리를 하자」

첫 수확을 마치면 만수가 「밥은 먹고 다니나」 하고 묻는다. 거기서 시작해
먼지 밑의 조리대를 찾아내고, 첫 끼를 지어 그에게 가져가면 파는 법과
먹는 법을 배운다 — **그것으로 메인 스토리 2가 끝난다.**

관련 코드: `game_data.gd`(상태·조건) · `story.gd`(대사·진행) ·
`village_ui.gd`(만수와의 대화 세 갈래) · `interior_ui.gd`(청소·조리대) ·
`dev_harness.gd` 스텝 288(`KITCHEN_OK`)

> **용어**: 이 게임에는 「부엌」이라는 말이 없다. 집 안에서 요리하는
> 자리는 언제나 **조리대**다. 새 글을 쓸 때도 이 말만 쓴다.

---

## 1. 상태 데이터

```gdscript
var kitchen_quest := ""     # "" / broom / make / sweep / found / jam / deliver / done
const JAM_ID := "dish_berry_jam"   # 첫 요리 = 산딸기잼
const JAM_BERRIES := 3             # 함께 주는 산딸기
```

| 값 | 뜻 | 다음으로 가는 조건 |
|----|----|------------------|
| `""` | 아직 | **만수와의 대화** (첫 수확 뒤) |
| `broom` | 빗자루 레시피 사기 | 레시피를 손에 넣음(구매/습득) |
| `make` | 잡초 모아 빗자루 만들기 | 가방에 빗자루 |
| `sweep` | 집 안 먼지 쓸기 | `kitchen_found`(먼지 3회) |
| `found` | 만수에게 알리기 | 만수와 대화 → 잼 레시피·산딸기 선물 |
| `jam` | 조리대에서 요리 짓기 | `recipes_cooked[JAM_ID] > 0` |
| `deliver` | **요리를 만수에게 가져가기** | 요리를 들고 만수와 대화 |
| `done` | 끝 — 파는 법·먹는 법까지 배웠다 | — |

**발동 가능 조건** (`kitchen_quest_ready()`)
`village_built.has("general")` · `not kitchen_found` ·
`kitchen_quest == ""` · **`story2_phase == "cook"`**(첫 수확을 마쳤다).

**요리 레시피 판매 게이트** (`cook_shop_open()`)
`kitchen_found and kitchen_quest in ["", "done"]` — 조리대를 찾았고
이야기를 마쳐야 잡화점·노점의 요리 레시피를 살 수 있다.

## 2. 시작점은 하나뿐

예전에는 잡화점에서 하는 세 가지 행동이 저마다 방아쇠였다 —
요리 레시피를 사려 할 때(A), 뭔가 사고 나가려 할 때(B), 그냥 나가려 할
때(C). 언제 시작됐는지 알기 어렵고, 나가려는 손님을 붙잡는 것도
답답했다. **세 갈래를 모두 없앴다.**

```
첫 수확 (tutorial_notify "harvest")
   └─ story2_phase: farm → cook     목표: 「만수와 대화하자」 · 만수 머리 위 ❗
        └─ 만수와 대화  → kitchen_quest = broom  (여기가 유일한 시작점)
```

- 가게를 나설 때 붙잡지 않는다 (`shop_room.try_leave`는 언제나 통과).
- 레시피를 사려 하면 여전히 팔지 않지만, 거기서 이야기가 시작되지는
  않는다 — 만수가 한마디 거들 뿐이다 (`kitchen_block_line`).

## 3. 끝은 「가져가기」다

요리를 지으면 끝이 아니라 `deliver`로 넘어간다.

```
jam ── 요리를 지었다 ──▶ deliver  목표: 「요리를 만수에게 가져가자」 (❓)
                              │
                    빈손 ─────┤ 「어디 한번 보여 줘 봐」 (되돌려보낸다)
                              │
                    손에 들고 ─┴─▶ 칭찬 → **판매 시스템 안내** → done
```

만수가 알려 주는 두 가지 — 이것이 곧 판매 튜토리얼이다.

> 「하나, 여기 계산대에 가져오면 돈이 돼.
>  재료 그대로 파는 것보다 값을 더 쳐 준다고.」
>
> 「둘, 가방에서 바로 먹을 수 있어.
>  배가 든든해야 하루가 길어지는 법이지.」

대화가 끝나는 순간 **메인 스토리 2가 완결**된다 (`story2_phase = "done"`).
상점 안에서 완결 배너와 함께 창이 하나 뜬다 — 상점이 서고, 바닷길이
열리고, 첫 작물을 거두고, 그 작물로 첫 끼를 지어 먹었다는 이야기.

## 4. 그리고 메인 스토리 3으로

2장이 끝나는 순간 `move_day = day`가 찍힌다. 그날은 자유롭게 보내고,
**침대에서 자고 일어나면** 문 앞에 이주 희망 편지가 놓여 있다
(`story._move_update` → `move_quest = "letter"`). 그 편지를 읽는 것으로
메인 스토리 3 「새로운 주민의 이사」가 시작된다.

```
2장 완결 (만수의 판매 안내)
   └─ 자유 시간 → 잠 → 다음 날 아침
        └─ 이주 희망 편지 도착 · 읽는다 ──▶ 메인 스토리 3 시작
```

## 5. 옛 세이브

예전에는 첫 수확만으로 2장이 끝났다. 그렇게 끝낸 세이브에서 아직
조리대를 못 찾았다면, 불러올 때 `story2_phase`를 `cook`으로 되돌려
마지막 마디를 마저 걷게 한다 (`save_load`).

---

## 검증 (`dev_harness.gd` 스텝 288 · `KITCHEN_OK`)

- 첫 수확이 2장을 끝내지 않고 `cook`으로 넘어가며 만수에게 ❗가 뜬다
- 가게를 나서도 붙잡지 않고, 레시피 구매로는 이야기가 시작되지 않는다
- 만수와 대화해야 시작되고, 첫 대사에 「밥은」이 있고 「부엌」은 없다
- 빗자루 → 청소 → 조리대 → 선물 → 요리까지 걸음이 끊기지 않는다
- 요리를 지으면 `deliver`가 되고 목표가 「만수에게」로 바뀐다 (❓)
- 빈손으로 가면 되돌려보내고, 들고 가면 판매·먹기 안내가 나온다
- 그 대화로 `story2_phase`가 `done`이 되고 `move_day`가 오늘로 찍힌다
- 완료 목록에 「조리대에서 요리를 하자 — 첫 끼를 지어 나눴다」가 오른다
