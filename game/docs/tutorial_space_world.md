# 튜토리얼 공간과 세계 — 두 개의 땅

처음 눈을 뜨는 숲길은 **교진 마을이 있는 세계의 일부가 아니다.** 걸어서
마을로 이어지지도 않고, 월드맵에 실리지도 않는다. 튜토리얼이 끝나면
그 공간은 통째로 닫히고, 다시는 발을 들일 수 없다.

관련 코드: `main.gd`(세계 상수·통행 규칙·`world_rect`) ·
`story.gd`(숲길 배치·전환 연출·공간 닫기) · `world_gen.gd`(세계만 짓기) ·
`map_ui.gd`·`hud.gd`(지도·미니맵) · `game_data.gd`(`tutorial_space`·지역 해금) ·
`save_load.gd`(옛 세이브) · `dev_harness.gd` 스텝 233(`WORLDGATE_OK`) ·
스토리 하네스(`TUTSPACE_OK`)

---

## 1. 격자는 하나, 땅은 둘

```
y   0 ─────────────────────────┐
                               │  실제 세계 (WORLD_H = 120)
                               │  마을 · 농장 · 숲 · 동굴 · 능선 · 바다
y 119 ─────────────────────────┘

y 120~121                         (아무것도 없는 사이 줄)

y 122 ─────────────────────────┐
                               │  튜토리얼 전용 공간
y 134   숲길 (TUT_Y0)          │  TUTORIAL_REGION = Rect2i(0, 122, 62, 38)
                               │
y 159 ─────────────────────────┘
```

```gdscript
const WORLD_H := 120                 # 실제 세계의 높이
const TUT_Y0 := 134                  # 튜토리얼 숲길이 놓이는 줄
const TUT_DY := TUT_Y0 - 7           # 옛 숲길 좌표(y7~22)를 옮기는 값
const TUTORIAL_REGION := Rect2i(0, TUT_Y0 - 12, 62, 38)
const MAP_H := TUTORIAL_REGION.end.y # 격자 전체 높이 (두 땅을 담는다)
```

`grid`은 `MAP_H`줄을 갖지만 **세계를 짓는 일(`world_gen`)은 `WORLD_H` 위쪽에서만**
한다. 그 아래 띠는 `story._plant_story_forest()`가 손수 깐다 — 흙길 · 울타리 ·
길목의 나무와 바위 · 울타리 너머의 숲.

숲길 위아래로 열 줄씩 여유를 둔 것은 **화면이 온통 숲으로 차야** 「따로 떨어진
한 장의 공간」으로 보이기 때문이다. 예전처럼 스물몇 줄만 두면 화면 아래
3분의 1이 맵 밖 어둠으로 잘려 「끝이 보이는 무대」가 된다.

## 2. 통행 규칙 — 지금 있는 땅이 세계의 전부다

```gdscript
func _tile_accessible(t: Vector2i) -> bool:
	if GameData.tutorial_space:
		return TUTORIAL_REGION.has_point(t)   # 여기가 전부다
	if t.y >= WORLD_H:
		return false                          # 그 공간은 사라졌다
	if not region_open_at(t):
		return false                          # 아직 이야기가 닿지 않은 땅
	return VILLAGE_REGION.has_point(t) or ROAD.has_point(t) \
		or GameData.is_tile_owned(t.x, t.y)
```

- **튜토리얼 중**에는 마을·광장·농장 어디로도 한 칸도 갈 수 없다.
  길이 없어서가 아니라 **세계 자체가 닿지 않는 곳**이기 때문이다.
- **마을에 들어선 뒤**에는 `y >= WORLD_H`가 통째로 막힌다. 돌아가는 길도,
  뒷문도 없다.

## 3. 마을로 가는 길은 「걸어서」가 아니다

숲길 동쪽 끝(`STORY_ROAD_X1`)에 닿으면 화면이 어두워진다.

```
숲길 동쪽 끝에 선다
   └─ 페이드아웃 (0.6초)
        └─ _close_tutorial_space()   오브젝트 · 지형 · 지도의 기억까지 지운다
        └─ 주인공과 우체부를 마을 어귀(WORLD_ENTRY = 58, 9)로 옮긴다
   └─ 페이드인 (0.8초)
        └─ 배너 「교진 마을 도착」 → 우체부의 첫마디
```

`_close_tutorial_space()`가 하는 일은 세 가지다.

1. 그 자리의 오브젝트를 전부 걷어낸다 (`objects` · 화면의 노드까지)
2. 바닥을 잔디로 되돌린다 (흙길이 남아 있으면 「거기 뭔가 있었다」가 된다)
3. **탐사 기록(`GameData.explored`)에서 그 청크를 지운다** — 지도에
   지나온 길이 흔적으로 남지 않는다
4. `GameData.tutorial_space = false`

건너뛰기(`_skip_tutorial`)도 같은 문을 지난다 — 공간을 닫고 마을 어귀에
세운다. 안 그러면 세계 밖에 갇힌다.

## 4. 지도(M)와 미니맵은 「지금 있는 땅」만 그린다

```gdscript
func world_rect() -> Rect2i:
	if GameData.tutorial_space:
		return TUTORIAL_REGION
	return Rect2i(0, 0, MAP_W, WORLD_H)
```

`map_ui`는 이 사각 하나를 기준으로 **전부** 다시 잰다 — 배율의 기준 칸
크기, 원점, 끌기 한계, 구운 지형 그림의 크기, 보이는 칸의 범위,
세계의 테두리. `_visible_tile()`은 이 사각 밖이면 무조건 false다.

| | 튜토리얼 중 | 마을 도착 후 |
|---|---|---|
| 지도가 보여 주는 땅 | 숲길 한 장 (62 x 38) | 세계 (224 x 120) |
| 마을 · 농장 | 구름조차 없다 (아예 없는 땅) | 걸어 본 만큼 |
| 처음 시작한 자리 · 지나온 길 | 지금 서 있는 곳 | **그림에도 없다** |

구운 그림(`_bake`)도 이 사각만 굽는다. 그림의 크기가 통째로 달라지는
순간(튜토리얼 → 세계)에는 `ImageTexture`를 새로 만든다.

## 5. 세계는 처음부터 다 걸을 수 있다

한때는 마을을 중심으로 깊은 숲·초원·습지·솔숲·벼랑길을 이야기에 따라
하나씩 열었다(`REGION_UNLOCK`). 그런데 **걸어서 갈 수 있는 곳이 이야기
진도에 묶이자 가고 싶은 데를 못 가는 게임**이 됐다 — 특히 바닷가
벼랑길은 자기 자신을 잠갔다(바닷길을 여는 바위가 그 벼랑길 아래에 있다).

지금은 야생 지역 자물쇠가 **없다.** 「아직 이르다」는 느낌은 지형과
몬스터와 이야기가 만들지, 보이지 않는 벽이 만들지 않는다.

```gdscript
const REGION_UNLOCK := {}
func region_unlocked(_id: String) -> bool:
	return true
```

**메인 스토리 4의 마을 확장 구역은 그대로다**(`is_tile_owned`). 그건
게시판에서 재료를 들여 직접 여는 마을의 몸통이지, 세계를 막는 벽이 아니다.

> 지도의 검정과 통행은 다른 것이다. 검정은 「아직 안 가 봤다」는 표시이고,
> 출입을 정하는 것은 확장 구역 하나뿐이다. 둘을 하나로 묶으면
> 「가 보지 않아서 못 가고, 못 가서 가 볼 수 없는」 자물쇠가 된다.

## 6. 옛 세이브

| 상황 | 어떻게 되는가 |
|---|---|
| 세계 높이만큼만(120줄) 저장한 격자 | 세계 부분이 한 칸도 어긋나지 않았다 — **밭 상태를 그대로 살린다** |
| 마을에 이미 도착한 세이브 | `tutorial_space`가 없으면 **닫힌 것으로 본다** |
| 튜토리얼 도중에 저장한 세이브 | 그 숲길은 세계 안(y7~22)에 있었다 — 새 자리에 숲길을 다시 깔고 첫 자리에 세운다 |

옛 흙길·부두를 잔디로 되돌리는 청소는 **세계에만** 적용한다. 튜토리얼
공간의 숲길은 이야기가 깐 진짜 길이라 지우면 안 된다.

## 검증

**`dev_harness.gd` 스텝 233 (`WORLDGATE_OK`)**

- 격자에서부터 세계와 튜토리얼 공간이 갈라져 있다 (`WORLD_H < TUT_Y0`)
- 마을 도착 뒤에는 그 띠의 어느 칸도 지날 수 없고 지도에도 뜨지 않는다
- 구운 지형 그림의 높이가 `WORLD_H`다 (튜토리얼 띠가 그림에 없다)
- 공간을 닫으면 오브젝트도 탐사 기록도 함께 지워진다
- 마을 광장은 처음부터 열려 있다
- 이야기를 하나도 진행하지 않아도 깊은 숲 · 초원 · 습지 · 솔숲 ·
  벼랑길이 전부 열려 있다

**스토리 하네스 (`TUTSPACE_OK`)**

- 시작 자리가 세계 밖(`STORY_SPAWN.y >= WORLD_H`)이다
- 숲길 위는 걸어 다닐 수 있다
- 마을 · 광장 · 농장 · 세계의 남쪽 끝 — 어디로도 갈 수 없다
- 지도가 보여 주는 땅이 `TUTORIAL_REGION` 하나뿐이고,
  마을 칸은 보이지 않으며 시작 자리는 보인다

## 덧: 도착하는 순간 두 가지가 어긋나 있었다

**① 카메라가 숲에 남아 있었다.** 전환은 「페이드아웃 → 옮기기 → 페이드인」인데,
카메라 제한을 푸는 일(`_apply_story_camera`)을 **페이드인이 끝난 뒤**에 했다.
그 사이 카메라는 여전히 튜토리얼 띠(y 122~159)에 묶여 있어서, 마을에
도착했는데도 화면에는 **지나온 숲길이 그대로** 보였고 — 카메라가 거기서
마을까지 미끄러져 오는 동안 그 위를 걸어 다닐 수도 있었다.

지금은 **화면이 아직 검을 때**(`_do_world_entry`) 제한을 풀고 그 뒤에
`reset_smoothing()`으로 스냅한다. 순서가 뒤집혀 있으면 스냅해 봐야 옛
제한 안으로 다시 끌려 들어간다.

**② 컷신 잠금이 전환보다 먼저 풀렸다.** `_story_update`에는 「컷신인데
1.5초 넘게 아무 창도 안 뜨면 풀어 준다」는 안전장치가 있다. 그런데 전환
페이드는 0.6 + 0.3 + 0.8 = **1.7초**다 — 도착 대화가 뜨기 0.2초 전에
조작이 살아났다. 전환이 도는 동안에는(`_world_entry_running`) 그
안전장치를 재우다.

## 덧: 벼랑길이 자기 자신을 잠그고 있었다

바닷가 벼랑길(`bluff`, y 96~105)의 해금 조건이 `sea_open`이었다.
그런데 바닷길을 여는 길목 바위는 **y 107**이다 — 그 바위에 닿으려면
벼랑길을 지나야 하고, 그 바위를 캐야 `sea_open`이 된다.
**못 가서 못 캐고, 못 캐서 못 가는** 자물쇠였다.

```gdscript
"bluff": "fisher",   # 용식이 앞장서는 순간부터 열린다
    return sea_open or fisher_quest in ["follow", "open", "done"]
```

길을 안내하는 사람이 곁에 섰을 때 벼랑길이 열린다 — 이야기와도 맞는다.

**검증** (`dev_harness.gd` 스텝 235 · `VILLAGE_ENTRY_OK`)

- 튜토리얼 띠에 카메라가 묶인 상태에서 `_do_world_entry`를 태우면,
  주인공도 **카메라도** 마을에 와 있고 튜토리얼 숲길은 한 칸도 안 남는다
- 전환이 도는 동안 4초를 흘려보내도 컷신 잠금이 풀리지 않는다
- 용식과 내려가는 중이면 마을 광장에서 **길목 바위 앞까지 실제로 길이 이어진다**

## 덧: 숲길 밖으로 새어 나가던 것

튜토리얼 동안 걸을 수 있는 땅을 `TUTORIAL_REGION` **전체**로 두었다.
울타리는 세워 두었지만 그 너머도 통행 가능한 땅이라, 나무 사이 틈으로
빠져나가면 숲 바깥 풀밭을 마음대로 걸어 다닐 수 있었다 — **우체부와 말도
섞기 전에 길 밖으로 나가 버리는** 일이 그래서 생겼다.

```gdscript
func tutorial_walkable(t: Vector2i) -> bool:
	# 본길 (동쪽 끝 X1에 닿으면 마을로 넘어가는 연출이 시작된다)
	# + 갈림길의 북·남 갈래 (둘 다 막다른 길)
```

이제 **울타리 안**만 걸을 수 있다. 울타리 너머 숲은 배경이다 —
나무를 베어도 그 자리로 나갈 수 없다.

## 덧: 튜토리얼 지도의 이름패

「교진 마을 · ○○의 농장」이라고 적혀 있었다. 주인공은 아직 그 마을을
본 적도 들은 적도 없다. 튜토리얼 동안에는 **「마을로 가는 숲길」**이다
(`map_ui.map_plate()`).
