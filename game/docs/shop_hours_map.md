## 1. 공공 건물의 영업시간

```gdscript
const OPEN_HOUR := 9.0     # 문 여는 시각
const CLOSE_HOUR := 18.0   # 문 닫는 시각
const LUNCH_FROM := 12.0   # 점심시간 시작
const LUNCH_TO := 13.0     # 점심시간 끝
```

`GameData.shop_open_now()` 하나가 판단하고, `shop_closed_why()`가 이유를
돌려준다(`early` / `lunch` / `late`). **개인 주거지는 해당 없다** —
집 문은 언제나 열린다. 대상은 `shop_room.ROOMS`에 있는 건물 전부
(잡화점·대장간·목장 상회·수산시장·우체국·여관·연구소·도서관·마을회관).

- **문 앞에서**(`interact`) 닫혀 있으면 안에 들어가지 못하고, 왜 닫혔는지
  팻말로 알려 준다. 「점심 먹으러 갔습니다」 같은 문장이다.
- **안에 있다가 6시가 되면** 주인이 손님을 내보낸다 (`_closing_tick`) —
  「아이고, 벌써 여섯 시네.」 「이제 문 닫을 시간이니까 내일 다시 와~」
  대화가 끝나면 방이 닫히고 주인공은 문밖으로 한 발 밀려난다.
  가게 안에서 시간을 흘려보내도 **반드시** 밖으로 나가게 된다.
- 방 오른쪽 위에 영업시간과 지금 시각이 늘 적혀 있다.

## 2. 상점 — 「도구」 칸을 「레시피」 칸으로

잡화점 한가운데 선반 넷 중 셋째가 바뀌었다.

| 선반 | 무엇 |
|------|------|
| 씨앗 | 제철 씨앗 |
| 생활용품 | (만드는 법은 레시피 선반에서 판다는 안내) |
| **레시피** | 요리·생활용품·집터·스프링클러 — **배워서 만드는 것 전부** |
| 기타 | 꽃다발 같은 마음 |

도구와 부품(못·경첩)은 예전부터 대장간이 다뤘다 — 비어 있던 「도구」 칸을
없애고 그 자리를 실제로 쓰는 레시피에 내줬다.

### 산딸기잼 레시피는 상점에서 팔지 않는다

`SHOP_FOOD_IDS`에서 뺐다. 이제 얻는 길은 **퀘스트뿐**이다 —
조리대를 찾는 안내에서 만수가 건네거나, **용식의 집터 부탁을 끝내면**
수납 상자 레시피와 함께 들어온다(이미 배웠으면 조용히 건너뛴다).

## 3. 「사라지지 않는 말풍선」

안내 말풍선은 **주인공 머리 위**에 붙는 물건이다. 그런데 가게 방·집 안·
동굴에서는 주인공이 화면에 없어, 말풍선이 화면 한가운데에 붙박이처럼
떠 있었다.

- `hud.hide_bubble()` — 즉시 걷는다.
- 가게 방·집 안·동굴·전체 창이 열리는 순간 말풍선을 자동으로 걷는다.
- 가게에 들어설 때의 안내는 말풍선 대신 **방 위쪽 팻말**에 적는다
  (`shop_room.notice`, 4.5초).

## 4. 갇힘 구조대 (`main.rescue_trapped`)

세계는 자란다 — 구역이 열리고 닫히고, 건물이 서고, 지형이 바뀐다.
그 사이에 **못 지나가는 칸 위에 서 있게 되면** 사방이 막혀 영영 움직일 수
없다. 그래서 **1초에 한 번** 훑어본다.

- 주인공이 맵 밖·잠긴 구역·물 위에 있으면 `nearest_open_tile()`로
  가장 가까운 성한 땅에 내려놓고 한 줄 알려 준다.
- 마을 사람도 마찬가지 — 잠긴 구역이나 맵 밖으로 밀려났으면 제 집 자리로
  돌려보낸다.
- 실내(집·동굴·가게)에서는 돌지 않는다.

미탐사 지역은 **지도에서만** 구름으로 덮인다(밑이 한 점도 비치지 않는
불투명 세 겹). 세계 자체의 출입은 구름이 아니라 **구역 해금**이 막는다
(`is_passable` → `_tile_accessible`) — 안 열린 구역과 맵 밖은 애초에
발을 들일 수 없고, 어쩌다 들어가더라도 위의 구조대가 꺼내 준다.

## 5. 지도(M) — 더 넓게, 더 아기자기하게

- 그리는 면을 920x496 → **952x512**로 넓혔다 (좌우 여백을 걷어냈다).
  최대 배율도 5.0 → **6.5**.
- 종이 지도 같은 장식을 둘렀다 — 네 귀퉁이의 작은 나뭇잎,
  왼쪽 아래 **나침반 장미**(북쪽을 가리키는 붉은 침),
  오른쪽 아래 **범례**(내 위치 · 지금 목표 ♥ · 아직 안 가 본 곳 ☁).
- 장식은 전부 화면 가장자리에만 그린다 — 지형을 가리지 않는다.

## 검증 (`dev_harness.gd` 스텝 299 · `SHOPTIME_OK`)

- 8·9·11.5·12·12.9·13·17.9·18·22시의 열림 여부와 이유가 표대로 맞는다
- 가게에 들어가면 말풍선이 걷히고 방 안 안내가 뜬다
- 6시가 되면 「문 닫을 시간 … 내일 다시」 대사가 나오고 방이 닫힌다
- 닫힌 이유 세 가지 문장이 모두 있다
- 선반에 `tool`이 없고 `recipe`가 있으며, 산딸기잼은 상점 표에 없다
- 용식의 집터 보상으로 산딸기잼 레시피가 들어온다
- 잠긴 구역 한가운데·맵 밖에 두면 성한 땅으로 구조된다
- 지도 면적·최대 배율이 넓어졌고, 미탐사 칸은 불투명하게 가려진다
