# 날씨 — 기준 문서

날씨는 **그날 무엇을 할지**를 바꾸기 위해 있다.
예전에는 맑음/비/눈 셋뿐이었고 하는 일이 "비 오면 물주기 공짜" 하나여서,
하늘을 봐도 계획이 달라지지 않았다.

## 표 하나로 정한다 (`GameData.WEATHERS`)

날씨를 하나 더 넣을 때는 이 표에 **한 줄**이면 된다.

| 날씨 | 아이콘 | 계절 | 무게 | 밭 젖음 | 궂은 날 | 그날 할 일 |
| --- | --- | --- | --- | --- | --- | --- |
| 맑음 | ☀ | 사계절 | 100 | | | 기본 |
| 비 | ☔ | 봄·여름·가을 | 26 | O | O | 물주기를 쉰다 |
| 눈 | ☃ | 겨울 | 40 | | O | |
| 안개 | ≋ | 봄·가을·겨울 | 16 | | | **채집** — 들판의 채집물이 12개 → 26개 |
| 폭풍 | ⚡ | 여름·가을 | 11 | O | O | **목재** — 부러진 가지 12~30. 대신 작물 25%가 주저앉는다 |
| 별밤 | ✦ | 사계절 | 13 | | | **빛 재료** — 반딧불이가 계절 상관없이 3마리 → 9마리 |

- `wet` = 밭이 하루 종일 젖는다 (물주기를 안 해도 된다) — 비 · 폭풍
- `harsh` = 궂은 날. 축사가 있으면 동물이 알아서 배부르다 — 비 · 눈 · 폭풍
  (안개·별밤은 궂은 날이 아니다. 예전에는 "맑음이 아니면" 전부 궂은 날이었다)
- 날씨는 **날짜 해시로 결정**된다 — 저장할 필요가 없고 같은 날은 언제나 같은 날씨다.
  계절에 맞는 것들 중에서 무게로 뽑는다.

## 연금술과 이어지는 곳

빛 속성 재료가 귀한 것이 연금술의 병목이다 (달빛의 물 = 빛 6+).
**별밤**이 그 병목을 여는 날이다 — 반딧불이(빛 2)가 계절을 가리지 않고 쏟아진다.
**안개**는 채집물(약초·산딸기 = 생명 재료)을 두 배로 준다.

## 화면 효과 (`main._draw_weather`)

- 비: 가는 빗줄기 · 눈: 흩날리는 점
- **폭풍**: 굵고 비스듬한 빗줄기 + 5초쯤마다 번개 섬광
- **안개**: 화면 전체를 옅게 덮고 **가장자리로 갈수록 짙어진다**(가까운 곳만 또렷) +
  흘러가는 안개 띠
- **별밤**: 해가 지면(17시~) 반짝이는 알갱이, 일부는 십자로 크게 빛난다

효과는 `_camera_rect()`(지금 보이는 월드 범위) 위에 그린다.

## 하네스

- `WEATHER_ALL_OK` — 1년(4계절)을 돌려 **여섯 날씨가 실제로 다 나오는지** 본다.
  무게를 잘못 넣어 영영 안 나오는 날씨가 생기면 여기서 잡힌다.
- `WEATHER_WET_OK` — 젖는 날/궂은 날 분류가 맞는지
- 스크린샷: `_weather_fog.png` · `_weather_storm.png` · `_weather_star.png`
