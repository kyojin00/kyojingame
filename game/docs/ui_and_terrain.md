# 지형 고정 · 낚시 제한 · 길라잡이 · 그림 중심 UI

한 배치로 들어간 다섯 가지. 공통된 생각은 **「보이는 대로 믿을 수 있게」**다 —
지형이 갑자기 변하지 않고, 못 하는 일은 그 자리에서 말해 주고,
어디로 가야 하는지 지도에 찍히고, 무엇을 만들 수 있는지 그림으로 보인다.

관련 코드: `world_gen.gd` · `main.gd`(GATE_POS) · `game_data.gd`(can_fish/gate_visible) ·
`interact.gd` · `tool_use.gd` · `story.gd`(표지판) · `map_ui.gd` · `desk_ui.gd` ·
`dev_harness.gd` 스텝 289(`TERRAIN_UI_OK`)

---

## 1. 바다는 처음부터 그 자리에 있다

예전에는 바닷길을 열기 전까지 남쪽을 **숲으로 덮어 두었다가**, 길목 바위를
캐는 순간 그 숲을 물로 갈아 끼웠다. 그래서 「돌을 캤더니 눈앞의 숲이
바다로 변하는」 광경이 그대로 보였다.

이제 `_build_sea()`는 `sea_open`과 **상관없이** 늘 같은 지형을 깐다.

| 줄 | 지형 |
|----|------|
| `SEA_RIDGE_Y`(77) | 바위 능선 — `searock`이 줄지어 선다 |
| `SEA_GATE`(63·64, 77) | 길목 — 열기 전에는 `bigrock`(곡괭이로 캔다) |
| `BEACH_Y0`(78)~ | 모래사장 |
| `SEA_Y0`(83)~ | 바다 |

`_reveal_sea()`가 하는 일은 이제 **길목 바위 두 개를 걷어내는 것**뿐이다
(+ 해변 채집물·노점 배치). 지형은 한 칸도 건드리지 않는다.

## 2. 오래된 돌문은 때가 되어야, 마을 밖에 선다

`GameData.gate_visible()` — **메인 스토리 18이 시작된 뒤**부터 참
(`story18_phase != ""` 또는 19·20 진행 중).

- `_build_map()`·`spawn_gate()` 둘 다 이 조건을 먼저 본다. 거짓이면 아예
  놓지 않는다 (예전에는 처음부터 서 있었다).
- 자리도 완전히 옮겼다: `GATE_POS` 78,4 → 86,4 → **40,2**.
  광장 북쪽에 두었을 때는 잡화점·연구소 마당과 겹쳐 그림이 포개졌다.
  새 자리는 마을 부지(`VILLAGE_REGION`)와 큰길(`ROAD`) 바깥,
  옛 전망대 언덕과 동굴 입구 사이의 북쪽 숲이다 — 할머니의 시계를 찾아
  언덕을 오르내리다 못 보던 돌문이 눈에 들어오는 흐름이다.
  (하네스가 마을과 겹치지 않는지 매번 확인한다)

## 3. 낚싯대가 없으면 낚시도 없다

`GameData.can_fish()` = `is_tool_unlocked("rod")`.
낚싯대는 **용식의 부탁으로 바닷길을 열 때만** 받는다 —
`TUTORIAL_UNLOCKS["harvest"]`에서 `rod`를 뺐다 (예전에는 초반 안내에서
덜컥 열려, 강가에서 곧바로 낚시가 됐다).

물가에서 E를 누르거나(`interact.gd`) 낚싯대를 휘두르면(`tool_use.gd`)
머리 위 말풍선으로 한 줄만 말한다:

> 낚시대가 없다...

## 4. 지도(M)의 퀘스트 길라잡이 — **하트 하나뿐**

`map_ui._quest_guides()` — 미니창에 고정한 퀘스트(고정하지 않았다면
미니창에 떠 있는 그 퀘스트) **하나만** 읽어 목적지를 찍는다.
여러 개가 동시에 뜨면 어디가 어딘지 모르게 되기 때문이다.

- `_quest_spot(qid)`: 「사람」이 아니라 「장소」로 가야 하는 단계는 그 칸을
  돌려준다 — 동굴·온천·옛 농지·옛 헛간·전망대·돌문, 그리고
  **세울 건물 터**(첫 상점·우체국)도 여기에 들어간다.
- 장소가 없으면 담당 NPC가 서 있는 칸이 목적지가 된다.
- 그림: 두근거리듯 커졌다 작아지는 고리 두 겹 + 그 위의 **하트**.
  글씨는 작게(15) **퀘스트 이름만** — 설명은 Q창의 몫이다.

## 5. 제작대(책상) — 글자보다 그림

앞으로의 모든 UI가 따르는 원칙이다: **먼저 그림, 글자는 거들 뿐.**

```
┌ 🪵 낡은 책상   ⏱ 5.0초  ▤ 1칸                    E / ESC ┐
│ [🪑 전체] [🗡 도구] [🛏 가구] [🧹 생활]                    │  ← 탭도 그림
│ ┌────┬────┬────┬────┬────┬────┐                          │
│ │ 🧹 │ 🪴 │ 📦 │ 🗡 │ 🗡 │ 🛏 │  ← 큰 그림 + 작은 이름   │
│ │빗자루│화분│상자│돌창│돌검│침대│                          │
│ │🌿1 │🌿5 │🪵8 │🪵3🪨2│...│    │  ← 재료도 그림 + 개수    │
│ └────┴────┴────┴────┴────┴────┘     (모자라면 붉게)      │
│ ┌ [고른 것] 큰 그림 · 이름 · 재료(가진 수/필요 수) · 설명 ┐│
│ └                                          [🔨 만들기 ] ┘│
│ [🪵 손보기]  🪵20/…  🪨10/…   → ⏱ 4.0초  ▤ 2칸           │
└──────────────────────────────────────────────────────────┘
```

- 탭 갈래는 `desk_ui.cat_of(id)` — `kind`를 사람이 보는 말로 옮긴다.
  `tool` → 도구 / `furniture`·`bed` → 가구 / 나머지 → 생활.
  `tab_ids(key)`가 그 탭에 놓일 레시피를 돌려준다 (배운 것만).
- 만드는 중인 것도 그림 + 진행 막대로 줄지어 보여 준다.
- 재료 그림은 `_mat_tex()`가 `icon_wood`/`icon_stone` 같은 별칭까지
  훑어 찾는다. 못 찾으면 그때만 글자 한 자로 대신한다.

## 검증 (`dev_harness.gd` 스텝 289 · `TERRAIN_UI_OK`)

- 바다·모래가 `sea_open` 이전에 이미 깔려 있고, 길목만 `bigrock`
- `_reveal_sea()` 앞뒤로 **뭍의 지형이 한 칸도 바뀌지 않는다**
- 돌문: 조건 전 없음 → 조건 뒤 등장 · 어느 건물 마당과도 안 겹침
- 낚싯대 없이 물가에 쓰면 「낚시대가 없다...」 말풍선, 낚시 시작 안 됨
- 표지판이 서고, 선택지 첫 줄이 「…용식의 집으로 결정…」, 고르면 `built`
- 지도 길라잡이가 스토리 18(전망대) 단계에서 `HILL_POS`를 가리킨다
- 제작대: 탭 셋의 합 = 전체, 갈래가 맞고, 격자에 그림이 충분히 들어간다
