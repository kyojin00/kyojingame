# 동굴 — 기준 문서

## 크기와 화면

동굴은 **한 화면에 다 들어오지 않는다.** 예전에는 26 x 13칸이 화면에 통째로
보여서, 들어가는 순간 그 층에 뭐가 있는지 다 알 수 있었다 — 탐험이 아니었다.

| | 예전 | 지금 |
| --- | --- | --- |
| 1층 크기 | 26 x 13 | **42 x 28** |
| 층마다 | 그대로 | 가로·세로 **+2칸** (최대 76 x 52) |
| 화면에 보이는 범위 | 전부 | **20 x 11칸** |
| 화면 | 고정 | **주인공을 따라간다** |

- 그리기 배율 `ZOOM = 1.5` — 타일 한 칸이 48px로 보인다 (오브젝트도 그만큼 크다).
- **논리 좌표는 예전 그대로 「타일 x 32px」다.** 이동 속도·피격 거리 같은 값을
  건드리지 않으려고, 확대와 카메라는 **그리기에만** 적용한다
  (`_draw_cave`의 `draw_set_transform`). 균형이 흔들릴 일이 없다.
- 카메라는 동굴 가장자리를 넘어가지 않는다. 화면보다 좁은 층은 가운데 맞춘다.

## 미니맵 (오른쪽 아래)

한 화면에 안 들어오니 길잡이가 필요하다. **가 본 곳만** 드러난다
(`seen`, 주인공 둘레 15 x 11칸). 벽·광석·계단·상자·입구·내 위치를 표시한다.
오른쪽 **위**는 바깥 HUD(시계·의뢰 두루마리)가 덮으므로 아래에 둔다.

## 계단은 처음부터 있다

예전에는 **몬스터를 전멸시켜야** 상자가 나오고, 상자를 열어야 계단이 생겼다.
동굴이 넓어진 지금 그 규칙이면 넓은 층에서 마지막 한 마리를 찾아 헤매야 한다.
그래서 **계단은 층을 만들 때 입구에서 먼 곳에 놓는다** — 걸어서 찾으면 내려갈 수
있다. 상자는 여전히 전멸 보상이다. 하네스가 `CAVE_STAIRS_OK`로 계단이 늘
걸어 닿는 곳에 있는지 검사한다.

## 층 유형 (`LAYOUTS`)

예전에는 모든 층이 「테두리 + 8% 확률 기둥」으로 **똑같이** 생겼다. 1층이든
30층이든 눈에 보이는 것이 같아서, 승강기까지 만들어 놓고도 깊이 들어갈 이유가
없었다. 지금은 층마다 모양이 바뀐다.

| 유형 | 이름 | 생김새 |
| --- | --- | --- |
| `open` | 너른 굴 | 드문드문한 바위 (예전 그대로) |
| `pillars` | 돌기둥 숲 | 세 칸마다 규칙적인 기둥 — 사이는 언제나 지나갈 수 있다 |
| `maze` | 좁은 갱도 | 격자 미로. 짝수 칸을 기둥으로 두어 통로가 반드시 이어진다 |
| `cavern` | 동공 | 큼직한 바위 덩어리 서너 개 |

세계수 동굴은 언제나 `open`이다 (보스 층 연출을 방해하지 않게).

## 희귀 방 (`SPECIALS`, 2층부터 26% 확률)

| id | 이름 | 내용 |
| --- | --- | --- |
| `vein` | 광맥방 | 광석이 3배로 박혀 있고, 상자 광석도 2배 |
| `grove` | 이끼방 | 몬스터가 절반. 대신 상자에서 **약초**가 나온다 (연금술 생명 재료) |
| `treasure` | 보물방 | 상자가 **처음부터** 놓여 있고 보석이 더 들어 있다 |

층에 들어가면 이름이 뜨고(`floor_title`), 희귀 방이면 토스트가 함께 뜬다.

## 미니보스

**5층마다** 나무 정령(`treant`)이 버티고 있다. 체력은 `12 + 층 x 2`.
승강기 층이 5의 배수이므로, 「여기까지 왔다」는 표시가 곧 보스층이 된다.

## 걸어 닿는 곳에만 놓는다

미로·동공은 벽 배치에 따라 **섬**이 생길 수 있다. 거기에 계단이나 상자를 놓으면
층을 넘어갈 수 없다. 그래서 벽을 다 놓은 뒤 입구에서 flood fill로 `reachable`을
구하고, `_free_tile`은 **그 안에서만** 자리를 고른다.

하네스가 40개 층을 만들어 `CAVE_REACHABLE_OK`로 검사한다 (못 닿는 층 0이어야 함).
`CAVE_LAYOUT_OK`(유형이 섞여 나오는가) · `CAVE_MINIBOSS_OK`(10층에 보스) ·
`CAVE_SIZE_OK`(한 화면보다 확실히 넓은가) · `CAVE_STAIRS_OK`도 함께 본다.

## 늘릴 때

- 층 유형: `LAYOUTS`에 한 줄 + `_gen_floor`의 `match`에 분기 하나
- 희귀 방: `SPECIALS`에 한 줄 + 효과가 붙는 곳(광석 수·몬스터 수·상자 보상)에 조건 하나
