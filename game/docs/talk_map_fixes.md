## 1. 지도가 어긋나 보이던 진짜 이유

숲길에서 지도를 한 번 열면 그때 구운 그림(62x38)이 **영영 그대로** 남았다.
마을에 와서 다시 열면 세계 크기(224x120) 자리에 그 작은 그림을 늘여 그리니,
지형은 화면 한가운데 뭉쳐 있고 내 위치만 엉뚱한 데 찍혔다.

```gdscript
func _need_bake() -> bool:
    if _tex == null:
        return true
    if not (Net.is_host() or Net.is_guest()):
        return false        # <- 혼자 하면 여기서 끝. 다시 구울 길이 없었다
    return _bake_age > BAKE_EVERY
```

「혼자 할 때는 한 번만」이라는 뜻은 **열어 둔 동안 한 번**이었는데, 코드는
**한 판에 한 번**이 되어 있었다. 이제 `open()`이 `_bake_dirty`를 켜고,
그림 크기가 보여 줄 땅과 다르면 무조건 다시 굽는다.

## 2. 대화키(F) 손질 세 가지

| 무엇 | 예전 | 지금 |
|------|------|------|
| 사거리 | 48px (한 칸 반) — 딱 붙어야 걸렸다 | **96px (세 칸)** · 40px 안쪽이면 방향 무관 |
| 헛디딤 | 말이 없어도 「아직 말이 없다」가 매번 떴다 | 탈 말이 **곁에 있을 때만** 말 타기로 넘어간다 |
| 가게 안 | 계산대는 E뿐 | E·F 둘 다 · 안내 문구도 키를 읽어 쓴다 |

말 걸기와 말 타기가 같은 F인 것은 그대로다. `riding.can_toggle()`이
false면 **아무 일도 일어나지 않는다** — 대화키를 누르며 걷는 동안 화면에
아무 말풍선도 뜨지 않는다.

## 3. 말줄임표가 문장을 세 조각으로 쪼개던 것

`(눈앞에 우거진 숲이 펼쳐져 있다...)` 한 줄이 화면에서는 이렇게 보였다.

```
(눈앞에 우거진 숲이 펼쳐져 있다.
.
.)
```

`_split_sentences`가 마침표마다 끊은 탓이다. 게다가 닫는 괄호를 삼키는
자리에서 `for i in n` 루프의 `i`를 고쳐 봐야 다음 바퀴에 되돌아가므로,
괄호가 한 번 더 새 조각의 첫 글자가 됐다. 셋을 고쳤다.

1. **잇달아 오는 부호는 한 덩이** — `...` `?!` `…`
2. **괄호·따옴표 안에서는 끊지 않는다** — 여는 괄호와 닫는 괄호가
   서로 다른 화면으로 흩어지지 않게 (`depth`로 센다)
3. 그래도 부호만 남은 조각이 생기면 **앞 문장 꼬리에 붙인다**

## 4. 마을 이름도 내가 짓는다

생성창에 「마을」 칸이 생겼다 (비우면 `교진`). 대사·간판·지도·안내에
박혀 있는 기본 이름은 **화면에 나가는 길목에서** 바꿔 준다.

```gdscript
func localize(text: String) -> String:
    var n := village_base()
    if n == HOME_VILLAGE or text == "":
        return text
    return text.replace(HOME_VILLAGE, n)
```

수백 줄의 대사마다 `%s`를 심지 않은 이유는 하나다 — **한 줄만 빠뜨려도
그 대사에서만 옛 이름이 튀어나온다.** 길목은 넷이다: 대화창 본문·이름패
(`dialog_ui.clean_text`/`open`), 말풍선(`hud.show_message`),
스토리 배너(`hud.story_banner`), 지도 이름패(`map_ui.map_plate`).

## 5. 만수 이야기가 「대화하자」에 멈춰 있던 것

목표는 「만수와 대화하자」인데 말을 걸어도 그대로였다. 말을 걸면
`kitchen_quest`가 도는데, 메인 스토리 목표문은 `story2_phase`만 보고
있었기 때문이다. 이제 `cook` 마디는 **잔 단계를 그대로 이어서** 보여 준다.

> 잡화점 만수에게 말을 걸자 → 빗자루 레시피를 사자 → 빗자루 레시피를
> 배우자 → 풀숲에서 잡초를 모으자 → 책상에서 빗자루를 만들자 →
> 집 안 먼지를 쓸어 내자 0/N → 만수에게 알리자 → 조리대에서 요리를
> 하자 → 요리를 만수에게 가져가자

## 6. 브금 이음매

ogg는 샘플 하나 어긋나지 않고 되감긴다. 그런데도 「뚝」 하고 들리는 것은,
곡의 **끝맺음과 첫 마디가 원래 이어 붙으라고 만든 소리가 아니라서**다.
그래서 끝나기를 기다리지 않고 미리 겹쳐 튼다 — 마지막 2.2초 동안 지금
곡은 서서히 줄이고, 두 번째 플레이어가 같은 곡을 처음부터 서서히 키운다.
다 넘어가면 둘의 역할을 맞바꿔 다음 바퀴를 준비한다.

스트림의 `loop`는 그대로 켜 둔다 — 겹치기가 어떤 이유로든 어긋나도
소리가 아예 멎지는 않게 하는 안전망이다.

## 7. 바다는 처음부터 물이다

물 위는 걸어서 탐사할 수가 없다. 그래서 탐사 기록만 보면 남쪽 바다는
**영영 검은 구멍**으로 남았다 — 지도 아래쪽이 잘려 나간 것처럼 보인다.
뭍에 서서도 바다는 보이는 법이라, `SEA_Y0`(113)부터 세계 끝까지는
가 본 적이 없어도 물로 그린다 (`_seen_tile`의 첫 줄).

큰 지도와 미니맵이 같은 함수를 쓰므로 둘 다 한꺼번에 바뀐다. 뭍은
그대로다 — 안개 검사도 이제 **뭍만** 센다 (`SEA_Y0`까지).

**세계 안에서도 마찬가지다.** 예전에는 물을 세계의 높이(`WORLD_H`=120)까지만
깔았는데, 격자는 그 아래 튜토리얼 공간까지 이어져 있다. 그래서 모래사장에
서면 화면 아래로 몇 줄이 더 보이면서 **파란 띠가 끊기고 풀밭이 도로
나왔다** — 바다 건너에 초원이 있는 꼴이다. 이제 격자 끝(`MAP_H`=160)까지
물이다. **한 칸도 빼놓지 않는다** — 세계 밖의 튜토리얼 숲길도 예외가 아니다.

숲길이 살아 있는 동안에는 `story._plant_story_forest`가 제 바닥(잔디)을
먼저 깔고 그 위에 길과 울타리를 놓는다. 마을로 넘어가며 공간이 닫히면
(`_close_tutorial_space`) 그 자리는 **바다가 된다** — 예전에는 잔디로
되돌려서, 모래사장에 서면 파란 바다 밑에 초록 땅덩이가 떠 보였다.
카메라가 `CAMERA_ZOOM`=0.56이라 발밑에서 **열다섯 줄 아래까지** 비춘다.

## 검사

* **`SEAMAP_OK`** — 아무 데도 안 가 본 상태에서 바다 줄이 전부 보이고,
  그 칸들이 실제로 물이며, **격자 끝까지 물이 이어지고**, 튜토리얼
  숲길은 살아 있을 때는 제 땅·닫으면 바다이며, 뭍은 여전히 가려져 있다
* **`MAPBAKE_OK`** — 숲길에서 62x38로 굽고, 세계로 넘어가 다시 열면
  `_need_bake()`가 true이고 224x120으로 다시 구워진다
* **`TALKUX_OK`** — 세 칸 떨어진 사람에게 말이 걸린다 · 말이 없으면
  F가 조용하다 · 만수와 말을 튼 뒤 목표가 다음 마디로 넘어간다 ·
  `...` 한 줄이 한 페이지 한 문장으로 남는다
