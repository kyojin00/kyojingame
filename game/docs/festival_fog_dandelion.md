# 첫 해의 조용한 계절 · 먹구름 지도 · 민들레

한 배치로 들어간 세 가지. 관련 코드: `game_data.gd`(축제 조건·민들레 데이터) ·
`map_ui.gd`·`hud.gd`(먹구름) · `world_gen.gd`(민들레 자생) ·
`object_nodes.gd`·`inventory_ui.gd`(그림) · `dev_harness.gd` 스텝 294(`SEASONFOG_OK`)

---

## 1. 계절 축제는 두 해째부터

```gdscript
const FEST_FIRST_YEAR := 2        # 첫 한 해는 축제가 없다

func year_of_day(d: int) -> int   # 1년 = DAYS_PER_SEASON * 4 (=112일)
func fest_year_ok(d := -1) -> bool
```

`festival_of_day(d)`가 **첫 관문**에서 첫 해를 잘라 낸다. 이 함수를
거치지 않는 축제 경로가 없으므로(오늘 축제·진행·NPC 자리·낚시대회 보정·
광장 장식·이장 「축제 이야기」 선택지·HUD 줄), 한 줄로 전부 조용해진다.

- 첫 해에는 봄·여름·가을·겨울 축제가 **0회** 열린다.
- 두 해째 같은 날짜부터 예전대로 네 번 열린다 (표 자체는 그대로 둔다).
- 목록을 보여 주는 두 곳은 사정을 말한다:
  - Q창 「계절 축제」 — 「올해는 축제가 없다 … 다음 해 봄부터」
  - 마을회관 소식 — 「올해는 축제가 없다. 마을을 추스르는 해다.」
- 메인 스토리 14 「마을의 첫 축제」는 **계절 축제가 아니다** — 그대로 진행된다.

되돌리려면 `FEST_FIRST_YEAR`를 1로 내리면 끝이다.

## 2. 미탐사 지역 = 먹구름

예전에는 안 가 본 곳을 새까맣게 칠했다. 화면이 깨진 것처럼 보여서,
**불투명한 먹구름**으로 바꿨다 (밑은 여전히 한 점도 안 보인다).

```
바탕 FOG(0.13,0.14,0.19)  →  덩어리 CLOUD_MID  →  빛 받는 면 CLOUD_TOP
```

- 두 칸마다 큰 덩어리 하나(반지름 1.5~2.2칸)를 겹쳐 놓는다. 칸마다 하나씩
  찍으면 크기가 고르게 나와 물방울무늬처럼 보인다.
- 자리·크기·밝기는 `_cloud_rand(x, y, salt)`가 **칸 좌표로** 정한다 —
  지도를 다시 열어도 같은 모양이고 깜빡이지 않는다.
- `blink`로 아주 느리게 흔들려 흐르는 하늘처럼 보인다.
- 미니맵(좌상단)도 같은 팔레트·같은 규칙으로 덮는다.

## 3. 민들레 (`forage_dandelion`)

산자락에만 피는 노란 꽃. 여느 채집물과 같은 길을 탄다
(줍기 → 가방 → 도감 → 판매 → 연금술 재료).

| 항목 | 값 |
|------|-----|
| 이름 · 판매가 | 민들레 · 45G |
| 자생지 | `y <= main.MOUNTAIN_Y`(14) 위쪽 풀밭 — 그 아래로는 안 난다 |
| 확률 | 산자락 채집 리젠의 약 절반 |
| 연금술 속성 | 생명 1 · 빛 1 |
| 필드 그림 | `sprites/forage_dandelion.png` (64x64) |
| 가방 아이콘 | `sprites/icon_forage_dandelion.png` (32x32) |

**필드 그림과 가방 아이콘이 서로 다르다.** 들판에서는 한 포기로 서 있고,
가방에서는 꺾은 한 송이로 보이는 것이 자연스럽기 때문이다. 이를 위해
가방은 아이콘을 찾을 때 `icon_<id>`를 **가장 먼저** 본다
(`inventory_ui._item_entries`) — 앞으로 어떤 아이템이든 이 규칙으로
가방 그림만 따로 갈아 끼울 수 있다.

### 그림 다시 만들기

```
원본:  game/assets/ref/src/ref_dandelion.png        (필드용, 유저 그림)
       game/assets/ref/src/ref_dandelion_icon.png   (가방용 — 있으면 쓴다)
실행:  NODE_PATH=... node game/assets/ref/cut_dandelion.js
```

- 원본 배경이 흰색이어도 된다 — `cut_dandelion.js`가 **흰 바탕을 투명으로**
  뽑아내고 여백을 잘라 규격에 맞춘다 (밑동을 칸 바닥에 붙인다).
- 가방용 원본이 없으면 필드 그림을 줄여 임시로 쓴다. 나중에
  `ref_dandelion_icon.png`만 넣고 스크립트를 다시 돌리면 교체된다.

## 검증 (`dev_harness.gd` 스텝 294 · `SEASONFOG_OK`)

- 첫 해 112일 동안 축제 **0회**, 두 해째 같은 기간에 **4회**
- 첫 해 봄 14일 정오에 `festival_open()` 거짓 · HUD 축제 줄 빈 문자열
- 먹구름: 안 가 본 칸이 가려지고, 구름 색이 불투명하며 바탕보다 밝다.
  같은 칸이면 늘 같은 모양(`_cloud_rand` 결정적), 옆 칸이면 다른 모양
- 민들레: 필드 64x64 · 아이콘 32x32 · 서로 다른 그림 · 도감/아이템 목록 등록
- 리젠을 여러 번 돌려도 민들레는 **산자락에만** 돋는다
- 주우면 가방에 들어오고 도감에 오르며, 가방 아이콘은 `icon_forage_dandelion`
