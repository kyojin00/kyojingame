# 교진 팜 — 퀘스트 순서 기준 문서

이 문서는 게임 퀘스트의 **기준(single source of truth)** 이다.
퀘스트를 추가/수정할 때는 반드시 이 문서를 먼저 갱신하고,
`game/scripts/game_data.gd`의 `STORY1_QUESTS` 데이터를 여기에 맞춘다.

- 우측 상단 두루마리: 현재 퀘스트의 "해야 하는 일"을 짧게 표시
- Q 키: 상세 퀘스트 창 (① 퀘스트 이름 크게 → ② 해야 하는 일 → ③ 스토리)

---

## 메인 스토리 1 「우체부 아저씨와의 첫 만남」

튜토리얼 = 메인 스토리 1. 별도의 튜토리얼 모드/버튼은 없다.
주인공과 우체부 아저씨가 울창한 숲을 함께 지나 마을에 도착하고,
우체부 아저씨가 이장에게 편지를 전달하면 완료된다.
우체부 아저씨는 스토리가 끝날 때까지 주인공과 동행한다.

### 퀘스트 1 — 숲 안으로 들어가보기

- **해야 하는 일**: 숲 안으로 들어가 보자
- **스토리**: 할아버지가 집으로 가는 길이 힘들 거라고 했던 이유를 이제야 알 것 같다.
  그래도 집으로 가기 위해서는 이 숲을 지나가야 한다.
- 시작 연출: 숲 앞에서 잠시 멈춰 할아버지의 말
  『집으로 가는 길이 조금 힘들 거다』를 떠올리는 독백 (그때는 몰랐지만 이제 이해)
  → 독백이 끝나면 퀘스트 목표 표시
- 진행: 숲 안으로 일정 거리만 이동하면 자동 완료 (`story_phase: enter`)

### 이벤트 — 우체부 아저씨와의 만남

- **해야 하는 일**: 우체부 아저씨의 이야기를 듣자
- **스토리**: 숲 속에서 우체부 아저씨가 다가와 말을 걸었다.
  그도 마을로 가는 길이라고 한다.
- 진행 (`story_phase: approach`):
  1. 우체부가 화면 왼쪽에서 걸어와 말을 건다
  2. 대화 1부: 인사 → 이름 질문 「자네 이름이 어떻게 되나?」
  3. **이름 입력** → 유저 닉네임으로 저장 (`GameData.player_name`), 이후 항상 이 이름으로 부른다
  4. 대화 2부: 동행 제안 → 나무도끼 전달 → 퀘스트 확인 방법 안내
     (우측 상단 표시 + Q 키 상세)

### 퀘스트 2 — 나무도끼를 장착해보기

- **해야 하는 일**: 받은 나무도끼를 가방(I)의 슬롯에 장착해 보자
- **스토리**: 이장님께 전할 편지를 가진 우체부 아저씨.
  숲이 험해 혼자 가기 어렵다며 함께 가자고 했다. 길을 만들 나무도끼를 받았다.
- 진행: 가방(I)에서 빠른 슬롯(1~9)에 도끼를 넣으면 완료 (`story_phase: equip`)
- 규칙: 도구는 획득 → 가방 → 슬롯 장착 → 숫자키 선택 → 사용 순서를 지킨다

### 퀘스트 3 — 나무를 베어보자

- **해야 하는 일**: 도끼를 선택(숫자키)하고 나무를 클릭한 뒤 E 키로 베어보자
- **스토리**: 도끼를 장착했다. 길을 막는 나무를 베어 마을로 가는 길을 만들자.
- 진행: 나무 1그루를 완전히 베면 완료 (`story_phase: chop`)
- 벌목 단계: tree_01 → (1타) tree_06 → (2타) tree_09 → (3타) 제거

### 퀘스트 4 — 마을로 이동

- **해야 하는 일**: 우체부 아저씨와 함께 숲을 개척해 마을(동쪽)에 도착하자
- **스토리**: 길이 열리기 시작했다. 아저씨와 함께 숲을 빠져나가 마을로 향하자.
- 진행 (`story_phase: travel`):
  - 카메라 잠금 해제, 마을/건물 표시 시작
  - 우체부 아저씨가 주인공을 따라다닌다 (동행)
  - 이장 방향으로 안내 화살표 표시

### 퀘스트 5 — 이장에게 편지 전달

- **해야 하는 일**: 마을 이장을 찾아가자
- **스토리**: 드디어 마을이 보인다. 우체부 아저씨가 이장님께 편지를 전하면
  긴 여정이 끝난다.
- 진행: 이장(덕수) 근처에 도착하면 컷신 —
  우체부가 이장에게 걸어가 편지를 전달하는 대화 → **메인 스토리 1 완료** (`story_phase: done`)
- 완료 후: 우체부 아저씨는 인사하고 떠난다. 자유 플레이 시작.

## 스토리 완료 후 — 마을 생활 안내 (구 튜토리얼 목표)

스토리 1 완료 후 퀘스트 창에 순서대로 표시된다.
필요한 순간에 하나씩 안내하며, 달성 시 도구가 해금되기도 한다.
(`GameData.TUTORIAL_ORDER` / `TUTORIAL_UNLOCKS` / `TUTORIAL_REWARDS`)

1. 방향키/WASD로 움직여보자
2. 지도(M)를 열어 집과 마을 위치를 확인하자
3. 퀘스트 창(Q)을 열어 할 일을 확인하자
4. 할아버지의 연구 노트(N)를 펼쳐보자
5. 호미를 슬롯에 장착해 풀밭을 갈자
6. 밭에 씨앗을 심자
7. 물뿌리개로 물을 주자
8. 집(북서쪽)에 들어가 침대에서 잠자기
9. 다 자란 작물을 수확하자 - 매일 물주기!
10. 도끼로 나무를 베어 목재를 모으자
11. 곡괭이로 돌을 캐서 석재를 모으자
12. 울타리나 스프링클러를 설치해보자
13. 낚싯대로 물가에서 물고기를 낚자
14. 마을 잡화점에 들어가 보자(E)

## 반복 퀘스트

- **오늘의 의뢰**: 마을 광장 게시판. 매일 제철 작물 납품 의뢰 (날짜 해시로 결정적)
- **할아버지의 부탁**: 연구 노트(N)를 채워가는 장기 목표 (엔딩으로 이어진다)
- **마을 탐사**: 부지 6곳 구입 (동쪽 들판 → … → 깊은 숲)
