# 기본 컨셉

## 1. 상점은 「먼저 겪은 것」만 판다

집에서 만들어 봤거나 우연히 얻은 뒤에야 상점·대장간 목록에 뜬다.
처음 보는 물건이 진열대에 있으면 발견의 재미가 통째로 사라진다.

- `GameData.discovered[id] = 처음 얻은 날` 하나로 도감·상점·컬렉션을 다 굴린다
- **씨앗은 예외.** 씨앗까지 잠그면 농사를 시작할 수가 없다.
  제철 씨앗은 계절이 오면 자동으로 열린다
- 잠그는 것: 도구 · 장비 · 가구 · 물약 · 요리 · 레시피

## 2. 도감(N) — 네모칸 격자

지금은 줄글이라 스물다섯 마리를 세로로 훑어야 한다. 격자로 바꾼다.

- 칸마다 아이콘. **못 얻은 것은 어두운 칸에 물음표**
- 칸에 마우스를 올리면 설명 + **처음 얻은 날**
- 갈래: 작물 · 물고기 · 요리 · 광물 · 채집 · 몬스터 · 물약 · 사람
- 퀘스트/이야기 쪽은 지금처럼 줄글로 둔다 (읽는 것이라 격자가 안 맞는다)

## 3. 모으면 주는 선물 (메이플 몬스터컬렉션식)

- 「봄 작물 전부」 「강 물고기 전부」처럼 **묶음**을 정해 두고,
  다 채우면 보상
- 보상은 **점점 귀해지는 요리 레시피**
- 묶음은 도감 화면 위쪽에 진행도 막대로 보여 준다

# 메인 스토리 2 — 마을에 자리 잡기

**목표: 상점을 열고 주민 집 두 채를 세운다. 그리고 할아버지의 낡은 집을
차츰 고쳐 나간다.**

## 도착 직후

1. 이장과 대화 → 우체부 아저씨와 작별 → 이장이 할아버지 집을 안내
2. 집 안에는 **낡은 침대와 탁자 하나뿐**
3. 이장이 침대를 설명 — 밤에 자야 패널티가 없다, 밤에는 알 수 없는
   것들이 나온다 (제일 먼저 나오는 것이 지네)
4. 설명이 끝나면 **낡은 책상을 선물**로 준다

## 책상 = 제작대 (동물의 숲 느낌)

처음 받는 것은 **널빤지를 얹은 걸상 같은 것**. 여기서 물건을 만든다.

- 만들 때 시간이 걸린다. 업글할수록 짧아진다 (5초 → 3.5초 → 2초)
- ▶ **안: 칸 수도 같이 늘린다** (1 → 2 → 3). 시간만 줄이면 하나씩
  기다리는 지루함이 그대로다. 여러 개를 걸어 두고 딴 일을 하러 갈 수 있어야
  「작업대를 키운 보람」이 난다

### ▶ 안: 업글 경로 — **가구는 제작대에서 만들어 바꾼다**

물어보신 것에 대한 답이다. 두 가지를 갈라 둔다.

| | 어떻게 |
| --- | --- |
| **제작대 자신** | 제작대 앞에서 E → 「손보기」. 자기 자신은 자기로 못 만드니 여기만 예외 |
| **침대 · 그 밖의 가구** | 제작대에서 **새것을 만들어 놓으면 낡은 것과 바뀐다** |

이렇게 하면 제작대가 처음부터 쓸모를 갖는다 — 이장이 준 책상으로
침대를 만들고, 그 침대로 잘 자고, 다시 제작대를 키우는 고리가 생긴다.

재료는 **목재·돌 + 대장간에서 산 부품**으로 묶는다. 대장간에 갈 이유가
생기고, 「상점은 먼저 겪은 것만 판다」와도 맞는다.

| 단계 | 재료 | 효과 |
| --- | --- | --- |
| 낡은 책상 (이장 선물) | — | 5초 · 1칸 |
| 튼튼한 작업대 | 목재 20 · 돌 10 · 못 2 | 3.5초 · 2칸 |
| 장인의 작업대 | 목재 40 · 광석 8 · 경첩 3 | 2초 · 3칸 |

| 침대 | 재료 | 효과 |
| --- | --- | --- |
| 낡은 침대 (처음) | — | 아침 기력 70% |
| 나무 침대 | 목재 25 · 못 2 | 100% |
| 푹신한 침대 | 목재 30 · 천 5 · 우유 3 | 110% + 늦게 자도 덜 손해 |

요리는 조리대에서 한다 (지금 그대로, 나중에 손본다).

## 상점 짓기 — 쉬운 길

- **목재 30 · 돌 20** 정도로 뚝딱. **다음 날 아침에 완성**된다
  (그 자리에서 솟으면 무게가 없다)
- 완성된 다음 날 마을에 나가면 **분수대 앞에서 이장이 어떤 아저씨와
  이야기하고 있다** — 상점 아저씨다

### ▶ 상점1에서 파는 것 (비어 있던 자리)

「레시피로 바꿀까」에 대한 답: **둘 다 판다. 다만 갈라서.**

- **소모품은 물건으로** — 씨앗, 못, 천 같은 부품
- **가구는 레시피로** — 화분·의자·러그. 만들 거리를 주는 쪽이
  제작대를 키운 보람과 이어진다

| 갈래 | 처음 파는 것 |
| --- | --- |
| 씨앗 | 제철 씨앗 3~4종 |
| 부품 | 못 · 천 · 밧줄 |
| 레시피 | 화분 · 나무 의자 · 작은 선반 |

## ▶ 이장 집과 마을회관 (이야기하자던 것)

**안: 마을회관은 처음부터 있고, 이장 집은 퀘스트로 짓는다.**

- **마을회관은 처음부터.** 이장이 편지를 받는 곳이고 게시판이 붙는 곳이라
  없으면 스토리 1이 성립하지 않는다. 도착했을 때 마을이 텅 비어 있으면
  「마을」로 안 보이기도 한다
- **이장 집은 퀘스트로.** 「이장님은 아직 회관에서 주무신다」로 두면
  플레이어가 지어 드릴 이유가 생긴다. 상점 다음 차례로 좋다

## NPC 집 놀러 가기

나중 일감. 집마다 실내를 만들어야 해서 무겁다 — 상점·이장 집이
자리 잡은 뒤에 한다.

# 이사 = 편지 + 답장 고르기

새 NPC는 **편지로 먼저 묻는다.**

> 안녕하세요. 저는 유리라고 해요.
> 바닷가가 있는 조용한 마을에서 작은 카페를 운영하고 싶어요.
> 교랑빌리지에 빈 가게가 있을까요?

플레이어가 **답장을 세 마디로 조립한다.**

| | 고르는 것 |
| --- | --- |
| 첫 마디 | 🌸 환영해요 / 🤔 어떤 카페인지 궁금해요 / 🏡 마을이 작은데 괜찮나요 |
| 둘째 마디 | ☕ 자리를 마련해볼게요 / 🌊 해변이 어울려요 / 🌳 마을 중앙을 찾아볼게요 |
| 마지막 | 💌 꼭 놀러 오세요 / 💌 답장 기다릴게요 / 💌 더 생각해보고 알려주세요 |

**호감도 점수를 매기는 선택지로 만들지 않는다.** 대신 고른 조합이
**그 NPC가 어디에 자리 잡는지 · 처음 대사 · 첫 선물**을 바꾼다.
「정답을 고르는 문제」가 아니라 「내가 쓴 편지」가 되게.

▶ 안: 조합 27가지를 다 쓰지 않고 **둘째 마디로 자리를 정하고**,
첫/마지막 마디는 **말투(반가움 · 조심스러움 · 궁금함)** 로 묶어 대사를 고른다.

# 도서관 — 스토리 기록 (다시 읽기)

도서관에서 **지금까지 실제로 진행한 스토리를 처음부터 다시 읽을 수 있다.**

- 요약본이 아니다 — 게임에서 나왔던 **대사 원문 그대로**
- NPC와 나눈 대사 포함
- **플레이어가 골랐던 선택지**가 보인다
- 선택지에 따라 달라졌던 대사도 그 갈래대로 보인다

**만들 때 주의:** 다시 읽으려면 **지금부터 남겨야 한다.** 스토리 대사가
화면에 나올 때마다 (말한 사람 · 대사 · 고른 선택지)를 세이브에 쌓는
기록층이 먼저다. 이걸 늦게 붙이면 그전에 지나간 스토리는 되살릴 수 없다 —
바다·이사보다 **먼저** 붙여 둘 것.

# 바다 열기

## 낚시꾼 NPC

상점 아저씨 다음으로 들어온다. **전설의 황금잉어를 잡으러 온 사람**이고,
마을에 살고 싶어 한다 → 같이 바다 쪽으로 내려가며 **길을 연다**.

길을 열어 준 답례로 **간이 낚싯대**를 준다. 그 전에 한 번 묻는다:

> Q. 자네도 황금잉어에 관심이 있나?
> 1. 당연하다. 꼭 잡고 말 거다
> 2. 잘 모르겠다. 아직은 욕심이 없다

대사는 달라지지만 **낚싯대는 똑같이 준다.** (고르기를 손해로 만들지 않는다)

## 해변

- 바다를 열면 **해변도 같이 열린다**
- 해변 채집 — 기본: **조개 · 금속 고리 · 유리 조각** /
  희귀: **산호 조각 · 고대 조각**
- 해변은 **해수욕장으로 키울 수 있다.** 마을 상점에서 「제2호점(노점)」
  레시피를 사서 **플레이어가 자리를 골라** 연다

### 노점에서 파는 것

- 쓰레기통 레시피 — **목재 5 · 금속 고리 2**
- 화분 레시피 — **잡초 5** (잡초는 숲에서 채집)
- 낚시용품 — ▶ 안: **미끼(입질이 빨라진다) · 튼튼한 줄(판정 구간 확대) ·
  어롱(하루에 낚은 것을 한 번에 판다)**. 낚시를 이미 미니게임으로
  만들어 두었으니 그 손잡이를 건드리는 것들이 자연스럽다

# 축산 · 요리 잇기

**기르는 것 → 만드는 것**의 고리를 짧게 만든다.

- 닭 → 계란, 밀(벼) → 쌀
- 소 → 우유, 옥수수
- 우유 → **버터** (한 번 더 가공하는 단계를 넣는다)

| 요리 | 재료 |
| --- | --- |
| 계란후라이 | 계란 1 |
| 계란말이 | 계란 1 · 우유 1 |
| 오므라이스 | 계란 1 · 쌀 2 |
| 버터 | 우유 1 |
| 버터옥수수 | 버터 1 · 옥수수 1 |

💗 = **레시피 표기**다 (기획 원문 표기 그대로). 이 요리들은 컬렉션
보상으로 열리는 레시피로 넣었다.

# 확정된 진행 순서 (2026-08-12 정리)

상점 아저씨 입주 → 낚시꾼 NPC 등장 → 황금잉어를 잡으러 왔다는 이야기 →
낚시꾼과 바다 쪽으로 → 길을 연다 → 황금잉어 선택지(대사만 갈린다) →
간이낚싯대 획득 → **바다 해금** → **해변 해금** (조개 채집) →
해변을 해수욕장으로 업글 → 마을 상점에서 노점 레시피 구매 →
**노점 자리는 플레이어가 정한다** → 쓰레기통/낚시용품/화분 레시피 →
숲에서 잡초 채집 → 잡초 5개로 화분 제작
