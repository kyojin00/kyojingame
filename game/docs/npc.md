# 마을 사람 — 대사 · 선물 · 연애

## 대사

넉 줄을 돌려 쓰면 세 번째 대화에서 이미 다 본 게 된다. 갈래를 나눴다.

| 갈래 | 언제 |
| --- | --- |
| `married` / `dating` | 배우자 · 연인일 때 |
| `aff70` / `aff30` | 호감도가 그만큼 오르면 |
| 생일 | 그날 하루 |
| `weather` | 비 · 눈 · 폭풍 · 안개 · 별밤 |
| `morning` / `night` | 9시 전 · 19시 후 |
| `season` | 봄 · 여름 · 가을 · 겨울 |
| `lines` | 아무 때나 |

`GameData.npc_line()`이 **맞는 갈래를 전부 모아** 그 안에서 하나를 뽑는다.
좁은 것만 쓰면 그 계절 내내 같은 말을 하고, 기본만 쓰면 갈래를 나눈 뜻이
없어진다. 지금 다섯 명이 126줄이고, 하네스 `NPC_LINES_OK`가 100줄 아래로
줄면 잡는다.

`secret50` · `secret100`은 그대로다 — 호감도가 오르면 40% 확률로 섞여 나오고,
할아버지의 과거가 여기서 밝혀진다.

## 선물

하루 한 번, 상대마다 다르게 오른다.

| | 호감도 |
| --- | ---: |
| `loves` 아주 좋아함 | +30 |
| `likes` 좋아함 | +18 |
| 표에 없는 것 | +8 |
| `hates` 싫어함 | **-6** |

**생일에는 세 배.** 생일은 `birthday: [계절, 날]`이고, 연구 노트(N)에
늘 적혀 있다. 취향은 호감도 30부터 노트에 보인다 — 처음부터 다 보이면
찾아내는 재미가 없다.

## 연애

되돌릴 수 없고, 각각 한 사람뿐이다.

```
호감도 60 + 꽃다발(800G, 잡화점)      -> 연인
연인 + 호감도 100 + 청혼 반지(12000G, 대장간) -> 배우자
```

순서를 건너뛰면 거절한다 — 이른 꽃다발도, 연인이 아닌데 내민 반지도
그대로 돌려준다 (하네스 `ROMANCE_OK`가 네 갈래를 다 확인한다).

연애할 수 있는 사람은 `romance: true`인 셋 — 만수 · 용식 · 보라.
무쇠와 덕수는 마을 어른이라 웃으며 돌려준다.

### 결혼한 뒤

마을을 걸어다니는 NPC를 집 안으로 옮기려면 실내 장면과 길찾기를 새로
짜야 한다. 그래서 **아침 결산에 한마디를 얹는** 쪽으로 했다
(`day_cycle._spouse_morning`).

- 매일 아침 배우자의 한마디 (`married` 대사에서 뽑는다)
- **이틀에 한 번** 자기 일에서 나온 것을 머리맡에 둔다 —
  만수는 딸기잼, 용식는 잉어, 보라는 우유
- 배우자 생일이면 선물 대신 알려 준다

## 새 사람을 넣을 때

`GameData.NPCS`에 한 칸 늘리고 `affinity`에도 같은 열쇠를 넣는다.
그림은 `npc_<id>_{down,up,side}_{0,1}.png`와 초상
`npc_<id>_portrait_{normal,happy}.png`가 있어야 한다.
