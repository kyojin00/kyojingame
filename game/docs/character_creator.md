# 캐릭터 생성창 — 시작하기 전에 나를 만든다

관련 코드: `title.gd`(`_build_gender_panel`/`_appear_refresh`/`_creator_report`) ·
`game_data.gd`(`APPEAR_SKIN`/`APPEAR_HAIR_COL`/`recolor_player_image`/`farm_title`) ·
`save_load.gd` · `story.gd`(우체부 첫 만남) · `map_ui.gd`(이름패) ·
`ending_ui.gd`(통계 첫 줄) · 검사: 타이틀 프레임 42의 `CREATOR_OK`

---

## 한 판 위에 전부

「새로 시작」을 누르면 타이틀 차림(제목·부제·메뉴)이 잠시 물러나고
나무판 하나가 화면 한가운데 놓인다. 왼쪽은 액자, 오른쪽은 고르는 자리다.

```
┌──────────────────────────────────────────────┐
│               새 농부 만들기                  │
│  ┌────────┐   이름   [            ]          │
│  │        │   농장   [            ]          │
│  │  도트  │   머리   ◀   긴 머리   ▶         │
│  │  미리  │   머리색 ■■■■■■■■                │
│  │  보기  │   피부   ■■■■■■                  │
│  │        │   상의   ■■■■                    │
│  └────────┘   바지   ■■■■                    │
│   [♂] [♀]     신발   ■■■■                    │
│        이 사람으로 시작!   돌아가기           │
└──────────────────────────────────────────────┘
```

**고르는 것은 전부 눈으로 본다.** 색은 「파랑·분홍·초록」 같은 이름표가
아니라 **그 색으로 칠한 네모**를 직접 누른다. 고른 칸은 테두리가 밝은
나무색으로 굵어진다. 성별은 글자 대신 ♂♀ 표식, 머리 모양만 이름이 있어
화살표로 넘긴다.

무엇을 누르든 **왼쪽 액자가 그 자리에서 갈아입는다.** 액자 속 농부는
가끔 눈을 깜빡인다 (`_blink_t`) — 가만히 서 있어도 살아 있어 보이게.

## 색은 어떻게 바뀌나

도트는 **표준 팔레트 한 벌로만** 그려져 있고, 실행 중에 픽셀 색을
바꿔치기한다(`recolor_player_image`). 옷·바지·신발이 원래 그랬고,
여기에 **피부와 머리카락**을 더했다.

| 표 | 칸 | 무엇 |
|----|----|------|
| `APPEAR_SKIN` (6벌) | 기본 · 밝은 면 · 그늘 · 볼 · 입 | 얼굴과 손발 |
| `APPEAR_HAIR_COL` (8벌) | 기본 · 밝은 면 · 그늘 | 머리카락 |

원본 도트에서 실제로 쓰이는 색만 골라 표를 짰다. 그래서 **테두리
(54,33,26) · 눈(66,32,30) · 눈썹(136,70,42)은 표에 없다** — 피부를 아무리
어둡게 해도 얼굴선이 뭉개지지 않는다.

민머리(`new_boy`)에는 머리카락 픽셀이 아예 없다. 그래서 머리 모양이
민머리일 때는 **머리색 줄이 흐려진다** — 눌러도 안 바뀐다는 것을 색으로
알려 주는 셈이다.

## 이름과 농장 이름

둘 다 여기서 짓는다.

* **이름** (최대 8자) — 비워 두면 「친구」. NPC 대사·장터 이름표에 쓰인다
* **농장 이름** (최대 12자) — 비워 두면 「<이름>의 농장」 (`farm_title()`)

농장 이름이 나타나는 곳: 지도 이름패(`교진 마을 · 햇살 농장`),
엔딩 통계의 첫 줄.

## 우체부 아저씨는 이미 알고 있다

예전에는 숲에서 우체부가 이름을 묻고, 그 자리에서 입력창이 떴다
(`_show_name_input` — 지금은 없다). 이름을 생성창에서 정하게 되면서
그 장면은 **통성명 한 마디**로 바뀌었다.

> 「그러고 보니 통성명이 늦었구먼. 나는 이 길을 삼십 년째 걷고 있는
> 우체부라네.」
> (나는 이름을 밝히고 짧게 인사했다.)
> 「〇〇(이)라... 좋은 이름이구먼.」

연출이 끊기지 않고, 조작 잠금(`_name_layer`)도 통째로 사라졌다.

## 검사 (`CREATOR_OK`)

타이틀 화면 42프레임째에 실제로 골라 보고(여자 · 긴 머리 · 금발 ·
볕에 그은 피부 · 분홍 상의 · 이름/농장 입력) 액자의 픽셀을 센다.

* **머리색 / 피부** — 고른 색이 실제로 도트에 칠해졌는가 (0이면 실패)
* **옛색남음** — 원래 팔레트가 한 칸도 안 남았는가
* **스와치** — 늘어놓은 네모 수가 팔레트 벌 수와 같은가
* **이름·농장칸** — 입력칸이 값을 받는가

스와치만 눌리고 그림은 그대로인 경우를 잡기 위한 검사다.
