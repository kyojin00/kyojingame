# 돌문 철거 · 퀘스트 창 통일 · 안내 순서 · 대사 다듬기

한 배치로 들어간 다섯 가지. 공통된 생각은 **「보이는 것이 하나뿐이게」**다 —
길을 막는 것은 치우고, 두 창은 같은 퀘스트를 가리키고, 목표는 한 번에
하나만 뜨고, 대사에는 말만 남는다.

관련 코드: `world_gen.gd`·`save_load.gd`(돌문 철거) ·
`game_data.gd`(`quest_list`/`farm_chain_open`) · `quest_ui.gd`·`hud.gd` ·
`dialog_ui.gd`(대사 다듬기) · `story.gd`(용식) ·
`dev_harness.gd` 스텝 289·296·298·322

## 1. 오래된 돌문 — 세계에서 완전히 삭제

상점 터와 겹쳐 길을 막던 문제를 자리 옮기기로 두 번 손봤지만
(78,4 → 86,4 → 40,2), 그때마다 다른 건물 마당과 부딪혔다. 뿌리를 잘랐다.

지운 것: `old_gate` 오브젝트 종류 · `main.GATE_POS` ·
`GameData.gate_visible()` · `world_gen.spawn_gate()`/`open_gate()` ·
`object_nodes`의 그림 갈래 · `interact`의 상호작용 ·
그림 파일 `assets/sprites/old_gate.png`.

옛 세이브 대비 — **두 겹으로** 걷어낸다.

1. 불러오는 중: 오브젝트 목록에서 `old_gate`를 건너뛴다 (`save_load`)
2. 불러온 뒤: `world_gen.purge_old_gate()`가 남은 칸을 한 번 더 훑는다

**스토리 20은 그대로 산다.** 「가장 오래된 자리」의 돌문을 동굴 가장
깊은 곳으로 옮겼다 — 마지막 페이지의 단서가 동굴을 가리키고, 동굴
입구에서 E를 누르면 이야기가 이어지며, 생명의 물 일곱 병을 부으면
가장 깊은 곳이 열린다. 지도 길라잡이도 동굴 입구를 찍는다.

## 2. Q창과 우측 미니창은 같은 목록을 본다

예전에는 Q창이 `quest_catalog()`를 **한 번 더 걸러서**(메인 이야기는
하나만) 보여 주고, 미니창은 걸러지지 않은 목록의 맨 앞을 집었다.
그래서 둘이 서로 다른 퀘스트를 가리키는 일이 생겼다.

이제 거르는 자리는 `GameData.quest_list()` 한 곳뿐이다.

```
quest_catalog()  ─ 모든 진행 중인 퀘스트 (원본)
      ↓
quest_list()     ─ 메인 이야기는 하나만. **고정한 퀘스트가 메인이면 그것이 그 하나**
      ├→ quest_ui   (Q창 목록)
      └→ tracked_quest() → hud (우측 미니창)
```

- 고정(핀)한 퀘스트가 있으면 **무조건** 그것이 미니창에 뜬다.
- 고정한 퀘스트가 끝나 목록에서 사라지면 `tracked_pick`을 스스로 비우고
  맨 앞으로 돌아간다 (끝난 퀘스트를 붙들고 있지 않는다).

## 3. 밭 갈기 안내는 바다를 연 뒤에

`GameData.farm_chain_open()` = `story2_phase in ["farm", "done"]`.

`tutorial_current_flag()`가 밭 갈기 줄기(호미→씨앗→물→수확→요리)를
이 조건 뒤에만 돌려준다. 호미는 상점이 서고 용식과 바닷길을 연 다음에
이장이 준다:

```
shop(상점 짓기) → fisher(용식과 바다) → farm_talk(이장에게) → farm(호미 · 밭)
```

그전에는 안내 목표가 `""`라, 상점·바다 퀘스트와 나란히 떠서 헷갈리던
일이 사라졌다. 화면에는 언제나 지금 할 일 하나만 남는다.

## 4. 대사에는 말만 남는다 (`dialog_ui`)

- `clean_text()` — 편집용 강조 기호(`**`)와 이어진 공백을 걷어낸다.
  `open()`·`set_body()`·`open_seq()` **모든 출구**를 지난다.
  데이터 쪽 문자열에 남아 있던 것도 함께 지웠다.
- **NPC가 입으로 하는 말**(「」로 묶인 대사)에서는 괄호로 적어 둔 지문을
  떼어낸다. 말풍선 안에 「…」와 (지문)이 섞이면 읽기 어렵기 때문이다.
  지문만 있는 페이지(연출)는 그대로 둔다.
- 한 페이지는 **세 줄까지**(`PAGE_LINES`). 예전 두 줄에서는 조금만 길어도
  문장이 다음 창으로 끊겨 넘어갔다. 세 줄로 넓히면 웬만한 한 문장이
  한 화면에 들어가고, 그래도 안 담기는 아주 긴 문장만 나뉜다.

## 5. 용식 — 첫 만남과 집 부탁을 갈랐다

| 언제 | 무슨 이야기 |
|------|-------------|
| 바다에서 첫 만남 (`fisher_quest = "meet"`) | 황금잉어를 쫓아왔다는 것, 큰 놈은 바다를 오간다는 것, 같이 남쪽으로 가 달라는 것 — 그뿐이다 |
| 사흘 뒤 분수대 앞 (`fisher_home = "wait"`) | 이 마을이 좋아져 짐을 풀고 싶다는 이야기, 살 집 한 채를 지어 달라는 부탁 |

첫 만남에 있던 「눌러앉을 작정이야」 한 줄을 걷어냈다. 정착 이야기는
서브 퀘스트가 열릴 때 처음 나온다.
