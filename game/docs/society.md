# 사회 — 호칭·법·직업·읍

「남이 나를 그렇게 부른다」에서 시작해 「판사가 되어 본다」까지. 사회 층은 헌법(`wf/constitution.md`)의
S1~S4 와 그 뒤 S5a~S5j 로 지어졌고, 이 문서는 그 결과물의 지도다. 조각마다 지은 것과 헌법과 다른 곳은
`wf/s2c~s5j_notes.md` 에 있다.

## 어디에 있나

| 파일 | 맡은 일 |
| --- | --- |
| `society.gd` (~3000줄) | 플레이어 쪽 행위 — 창구·근무·범죄·체포·재판·좌판·읍 장부. `m.` 으로 세계를 든다 |
| `game_data.gd` 사회 구역 | 순수 데이터와 아침의 규칙 — `society_new_day()` 가 하루 한 번 돈다(day_cycle 이 부른다) |
| `npcs.gd` · `npc.gd` | 사회가 정한 자리(society_place)·읍 사람·생성 NPC 노드·순경 교대 |
| `village_ui.gd` | 창구 대화 배선(회관·읍 관청·정류장·장터) |
| `dev_harness.gd` | 검사 — 아래 표 |

원칙 셋. **자리가 진실이다**: `seats[inst][rank]` 배열이 채용·승진·전근·구속의 유일한 기록이고 `me.job` 은
그 그림자(`society_new_day` ②가 매일 맞춘다). **돈은 창구로만 오간다**: 세금·벌금·봉급·인지세는 전부 창구 앞 E.
**호칭은 NPC 의 입으로 나온다**: `player_title()` 이 cls 를 정하고 `talk_opener()` 가 그날 첫마디로 만든다.

## 호칭과 대범함 (S1)

`player_title(nid)` → cls: murderer / seen(그 일 있던 사람) / heard(소문) / jailed / office(직함 — 근속 14일 뒤,
호감 70 이면 「우리 ○○」) / ex(전직) / free(자유직) / name / stranger. 자유직은 통계(`FREE_TITLES`)가 문턱을
넘으면 저절로 불린다 — 농부·어부·벌목꾼·광부·요리사·목장주·약초꾼·동굴꾼·목수.

대범함 `boldness()` = base(이장의 질문으로 정한다) + state(살아온 대로 오르내린다). 숫자는 안 보이고 단계 이름만.
문턱(`GATE`): 소매치기 20 · 빈집 35 · 순경 35 · 뇌물 40 · 도주 30 · 강도·주먹·법정 모독 55 · 살인 75.
55·75 는 회색이 아니라 **부재** — 소심한 사람은 생각조차 못 한다.

## 범죄와 기억 (S1·S2c·S5a)

| 행위 | 어디서 | 성공률 | heat |
| --- | --- | --- | --- |
| 소매치기 | 사람 앞 대화 | theft_p(0.25) | 1 |
| 좀도둑 | 상점 선반 | theft_p(0.35) | 1 |
| 빈집 잠입 | 정착민 집 문 | theft_p(0.30) | 2 |
| 강도·주먹다짐 | 사람 앞 대화 | 굴림 없음 | 3·2 |
| 살인 | 사람 앞 대화 | 굴림 없음 | 5 |

`theft_p` = base × 손버릇(`theft_lv`, 숨은 값) × 밤 1.3 × 0.85^목격자. 본 사람만 기억을 남긴다
(`me.memories`, `_remember`) — 목격자마다 신고 굴림(교진 0.4 · 읍 0.8, 호감이 높으면 덜, 생성 NPC 는 snitch 만큼).
대면 범죄는 피해자의 진술이 곧 목격이라(`facing_others`) 반드시 기소된다. 살인은 본 사람이 있으면 100%,
없으면 아무 데도 없던 일 — 사람은 `dead` 에 오르고 정착민은 집이 빈다.

교진의 신고는 **이장이 먼저 온다**(heat ≤ 1, 마을 회의: 배상/부인/자백·봉사). 빈집부터는 기소다.
읍의 신고는 곧장 경찰서 — 다음날 아침 수배.

## 경찰·수배·체포 (S2b·S4f)

교진: 박 순경(파출소 = 여관 부지). 수배(`me.wanted`)면 6~24시 나를 쫓고(`society_place` "chase"),
1.5칸 안 2초면 즉결(벌금 또는 사흘 봉사). 자수는 파출소 창구, 벌금 절반.
읍: 순경 셋(생성 g16~18, 세 교대 6·12·18시, 비번은 안 보인다). 수배면 셋이 협공하되 읍 밖으로는 안 나온다.
체포되면 유치 사흘 → 검찰 → 읍 법원. 뇌물(40, 500G) 성공 = 0.3×(2−snitch)/1.5, 실패면 같은 사건에 가중.
도망 수단은 말(대범함 30)·버스(30)·실내 — 실내는 문을 나서면 순경이 문 앞에 서 있다. 이레면 잊는다.

NPC 도 범죄한다(결정적 주기: 교진 7일·읍 3일). `cases` 가 순경 검거 → 검찰 → 판사로 흐르고,
플레이어 순경은 「출동」으로 흔적 둘을 모아 검거한다(무고면 평판 −5).

## 재판·형벌·전과 (S2c·S4f·S4g·S5h)

순회 재판(계절 7·21일, 회관, 윤 판사·한 검사)과 읍 법원(날마다, 서 부장·민 부장). 피고 진술: 인정/부인/사정/
대든다(55). 형량 단계 = heat + 거른 재판 + 뇌물 + 전과 − 자수 − 평판 40 ± 진술.
1 벌금 / 2 벌금+봉사 이레 / 3·4 구류 이레(낮 노역이면 나흘) / 5 징역 84일. 살인은 참작이 없다.
징역은 잿빛 벌판의 교도소 실내에서 **날짜를 한 번에 건너뛴다**(`serve_sentence`) — 밭은 마르고, 자리는 그날 비고,
나올 때 대범함 +5 · 호칭 「그 일 있던 사람」 이레. 벌금은 고지서(면사무소·군청), 전과 말소는 500G 에 28일 뒤.
플레이어 판사는 무죄/경감/법정형/가중, 가중받은 피고는 이레 뒤 밤 밭 서리를 별러 둔다(`grudges`).

## 세금·예산 (S2a·S4e)

교진: 계절 첫날 고지서(소득세 10% · 재산세 · 매출세 5%) → 면사무소 창구 납부. 체납 사다리 2주 독촉 · 4주 이장 ·
6주 봉급 정지 · 8주 압류. 예산 `gov_budget.kyojin` 은 교부금 + 장부세 − 운영비, 사업(`GOV_PROJECTS`) 은 예산이
차면 이장이 건다(등불 → 포장 → 버스 …).
읍: `town_season()` — 교부금 6,000 + 인구×60 − 운영비 2,520, 흑자의 반으로 빚을 갚고 사업(가로등·장터·주택가)을
건다. 기채는 군청 서기만(신협, 5,000, 이자 5%). 빚 1만/2만/3만에 긴축 1·2·3(사업 중단 → 밤 교대 없음 →
아침 교대뿐·이주 중지). 군청 창구 = 읍 장부 · 벌금 · 봉사. 계절 첫날 「갈뫼읍 소식」 편지.

간호사→의사, 읍 순경→경위). 그날 상급자의 첫마디가 통보다.

## 읍과 생성 NPC (S4b~S4d·S4h)

갈뫼읍은 억새 벌판에 처음부터 서 있다(`TOWN_PLOTS` 관청 여덟 + 장터 여덟 + 주택 여덟 + 교도소). 손글 아홉
(군수·서장·부장판사·부장검사·소장·지점장·주모·주인·장물아비)과 생성 NPC 스물셋: 상인 7 · 주택가 8(계절마다
둘씩 온다) · 순경 3 · 기관 직원 5(주사·경위·의사·판사·검사). 생성은 씨앗 하나로 결정적(`gen_make`):
이름·성격(snitch·greed…)·취향·팔레트. 직원은 4~8계절마다 전근으로 자리를 비우고(승진 공석), 두 계절 뒤 새
얼굴이 온다. 노드는 아침마다 `sync_gen_nodes` 가 맞춘다.

## 아침의 순서 (`society_new_day`)

② 자리→직업 정합 → ③ 계절 첫날: 읍 결산·소식지 → 교진 결산·고지서 → 체납 사다리 → 좌판 정산 → ⑤ 출근·봉급 →
NPC 범죄·사건 닫힘 → 수배 → 순회 기소 → 읍: 이주·전근·사건·앙갚음 → 자치회 → 호칭 변화.
낮에 생긴 줄(판결·주먹·살인·출소)은 `note_later` 로 다음 아침 맨 앞에 선다. 그 뒤 `society.after_new_day` 가
세계를 든 쪽의 일(노드 동기화·밭 서리·압류)을 한다.
