# 계정용 이미지

공식 계정(X · 유튜브 · 스팀)에 올릴 프로필·배너. **게임 자산에서 뽑아 낸 것**이라
캐릭터나 화면이 바뀌면 다시 돌리면 된다.

```
cd brand
node make_brand.js      # pngjs 필요. 게임 스크린샷(1_*.png)이 있어야 배너가 나온다
```

스크린샷은 하네스가 찍는다 — `KYOJIN_SHOT=1 godot --path game` 을 돌리면
`game/1_*.png` 60장이 생긴다.

| 파일 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `brand_profile_green.png` | 400x400 | 프로필 (잔디색 바탕) |
| `brand_profile_cream.png` | 400x400 | 프로필 (흙색 바탕) |
| `brand_banner_village.png` | 1500x500 | 배너 — 마을 광장 |
| `brand_banner_field.png` | 1500x500 | 배너 — 밭 |

## 만들 때 지킨 것

- **최근접 확대만.** 도트를 보간해서 늘리면 뭉개져서 도트 게임으로 안 보인다.
  프로필은 정수배(4배)로만 키운다
- **프로필은 얼굴만.** X는 48px로도 보여주는데 전신을 넣으면 아무것도 안 보인다.
  실루엣 위에서 45% 지점까지 잘라 쓴다
- **배너는 UI 없는 띠만.** 위는 미니맵·퀘스트창, 아래는 대사줄·소지품칸이 걸린다.
  `1_village.png` 기준 y210~630이 비어 있다 (화면이 바뀌면 다시 재야 한다)
- **가로도 같이 줄여 3:1을 맞춘다.** 세로만 늘리면 캐릭터가 20% 길어지는데,
  도트는 늘어난 게 바로 티가 난다
