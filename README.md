# 🌾 교진 팜 (Kyojin Farm)

스타듀밸리 느낌의 **도트 그래픽 농장 시뮬레이션 게임**입니다.
브라우저에서 바로 실행되며, 빌드 과정이나 외부 에셋 없이 순수 HTML5 Canvas + 바닐라 JavaScript로 만들어졌습니다.
모든 도트 그래픽은 코드로 직접 그립니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 플레이할 수 있습니다.

로컬 서버로 실행하려면:

```bash
# Python이 있는 경우
python3 -m http.server 8000
# → http://localhost:8000 접속

# Node.js가 있는 경우
npx serve .
```

## 게임 방법

핵심 루프: **밭 갈기 → 씨앗 심기 → 물 주기 → 수확 → 판매 → 취침(다음 날)**

- 물을 준 작물만 밤사이 자랍니다. 매일 물을 주세요!
- 다 자란 작물을 수확해서 출하 상자에서 팔아 돈을 법니다.
- 도구를 쓰면 기력이 소모됩니다. 새벽 2시까지 안 자면 쓰러집니다.

### 조작법

| 키 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| `Space` / `Enter` / 클릭 | 현재 도구 사용 |
| `1` | 호미 (밭 갈기 / 되돌리기) |
| `2` | 물뿌리개 |
| `3` | 씨앗 심기 |
| `4` | 수확 |
| `Tab` | 씨앗 종류 바꾸기 |
| `E` | 상호작용 (집 앞: 취침 / 출하 상자: 판매) |
| `B` | 상점 열기 |
| `Esc` | 창 닫기 |

### 작물

| 작물 | 씨앗 가격 | 판매가 | 성장 일수 |
|---|---|---|---|
| 🥔 감자 | 30G | 80G | 4일 |
| 🥕 당근 | 40G | 110G | 5일 |
| 🍓 딸기 | 60G | 170G | 6일 |
| 🎃 호박 | 100G | 320G | 9일 |

시작 자금 500G + 감자 씨앗 5개로 시작합니다.

## 저장

- 취침하면 자동 저장됩니다 (브라우저 localStorage).
- 상단의 "저장" 버튼으로 수동 저장도 가능합니다.

## 프로젝트 구조

```
index.html      # 페이지 및 HUD 마크업
style.css       # HUD/모달 스타일
js/sprites.js   # 도트 스프라이트 데이터 + 렌더링 헬퍼
js/crops.js     # 작물 정의 (가격, 성장 일수)
js/game.js      # 메인 게임 로직 (맵, 이동, 시간, 상점, 저장)
```
