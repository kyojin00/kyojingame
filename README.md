# 🌾 교진 팜 (Kyojin Farm)

스타듀밸리 느낌의 **도트 그래픽 농장 생활 시뮬레이션 RPG**.
스팀 출시를 목표로 **Godot 4 엔진**으로 개발 중입니다.

따뜻하고 힐링되는 농장 생활이지만, 후반으로 갈수록
**할아버지가 남긴 연구 노트**를 통해 숨겨진 연금술 이야기가 밝혀지는
스토리 중심의 게임입니다.

> **프롤로그** — 유명한 탐험가이자 연금술 연구자였던 할아버지.
> 사람들은 그의 연구를 허황된 꿈이라 비웃었지만, 그는 평생 포기하지 않았다.
> 할아버지는 마지막 연구를 완성하지 못한 채 세상을 떠났고,
> 남겨진 나무 상자에는 대부분 비어 있는 연구 노트와 편지 한 통.
> *"내가 이루지 못한 꿈을 네가 이어주었으면 좋겠다."*
> 편지에 적힌 마을, '교진 마을'로 주인공은 향한다.
> (할아버지가 무엇을 만들려 했는지는 게임 후반까지 밝혀지지 않습니다)

핵심 루프: **밭 갈기 → 씨앗 심기 → 물 주기 → 수확 → 판매 → 취침(다음 날)**
그리고 그 모든 발견이 **연구 노트(N)**의 빈 페이지를 채워갑니다.

## 프로젝트 구조

```
game/            # Godot 4 프로젝트 (메인 개발)
web-prototype/   # 초기 HTML5 프로토타입 (참고용, 브라우저에서 실행 가능)
ROADMAP.md       # 완성까지의 단계별 개발 계획
```

## 실행 방법 (Godot)

1. [Godot 4.4 이상](https://godotengine.org/download) 다운로드 (무료, 100MB 미만)
2. Godot 실행 → **가져오기(Import)** → 이 저장소의 `game/` 폴더 선택
3. 에디터가 열리면 **F5** (프로젝트 실행)

> 웹 프로토타입은 `web-prototype/index.html`을 브라우저로 열면 바로 실행됩니다.

> 처음 시작하면 **튜토리얼**이 화면 위 "다음 목표"로 기본 조작을 안내합니다.
> 처음엔 호미 하나뿐이지만, 목표를 달성할 때마다 **새 도구가 하나씩 해금**됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| `Space` / `Enter` | 현재 도구 사용 |
| `1` ~ `4` | 호미 / 물뿌리개 / 씨앗 / 수확 |
| `5` ~ `8` | 도끼 / 곡괭이 / 울타리 / 스프링클러 |
| `9` | 낚싯대 (물가에서 사용) |
| `Tab` | 씨앗 종류 바꾸기 |
| `E` | 상호작용 (집: 들어가기 / 출하 상자: 판매 / 대화 등) |
| `M` | 지도 열기 (집/마을/내 위치 확인) |
| `J` | 퀘스트 창 (튜토리얼/의뢰/목표, 오른쪽 고정) |
| `N` | **연구 노트** (도감 통합 + 스토리 진행) |
| `I` | 인벤토리 (도구 선택·보유품) |
| `U` | 능력치 창 (숙련도·펫) |
| `B` | 상점 열기 (구매/판매/업그레이드) |
| `F` (집 안) | 집 꾸미기 모드 |
| `F5` (게임 내) | 수동 저장 |
| `F11` | 전체 화면 토글 |
| `Esc` | 창 닫기 |

- 도끼로 나무를 베면 **목재**, 곡괭이로 돌을 캐면 **석재**를 얻습니다.
- 울타리(목재 1)와 스프링클러(목재 2+석재 2)를 설치할 수 있습니다.
  스프링클러는 매일 아침 주변 4칸에 물을 줍니다.
- 상점 강화 탭에서 호미/물뿌리개를 Lv2(전방 3칸)로 강화할 수 있습니다.
- 상점 동물 탭에서 닭/소를 입양하고, E로 쓰다듬어주면 다음 날 달걀/우유를 얻습니다.
- 낚싯대(9)로 물가에서 낚시: 입질(!)이 오면 Space → 타이밍 미니게임!
  잡은 물고기는 상점 도감 탭에 기록됩니다.
- 맵 동쪽 **마을**에 가면 NPC(민지, 철수)와 대화하고 선물해서 호감도를 쌓을 수 있습니다.
  호감도 50을 넘기면 NPC별 특전이 열립니다 — 민지: 씨앗 10% 할인 /
  철수: 낚시 판정 구간 25% 확대. **의뢰 게시판**에서 납품 의뢰도 받아 보세요.
- 도구는 인벤토리(`I`)에서 클릭하거나 숫자키로 고르고,
  타일 위에 뜨는 힌트(수확!/성장중/물주기!)를 따라가면 됩니다.
- **도구 자동 선택**: 나무 앞에선 도끼, 바위 앞에선 곡괭이, 물가에선 낚싯대,
  다 자란 작물 앞에선 수확 도구가 자동으로 잡힙니다.
- **능력치(숙련도)**: 농사/낚시/벌목/채광/전투/요리 — 반복할수록 레벨이 올라
  작물 성장, 입질 대기, 추가 획득, 공격력, 요리 회복량이 좋아집니다 (`I`에서 확인).
- **집 꾸미기**: 집 안에서 `F` — 가구 8종을 사서 자유롭게 배치/이동/판매.
- **요리**: 집 조리대(`E`)에서 레시피 10종. 먹으면 체력 회복, 팔면 재료보다 비쌉니다.
  만든 요리는 상점 **도감 탭**의 요리 도감에 기록됩니다.
- **펫**: 목장 상회에서 입양 — 강아지(이동 +10%) / 고양이(입질 -15%) /
  부엉이(동굴 피해 -25%) / 토끼(작물 성장 +5%). 한 마리가 곁을 따라다닙니다.
- 계절별 칩튠 BGM과 효과음이 나옵니다. 타이틀 **설정**에서 음량·화면 크기
  (창 1280x720/1920x1080, 전체 화면)·**키 설정**(리바인딩)을 바꿀 수 있습니다.
- 화면 오른쪽 위에 현재 목표/의뢰/연구 노트 진행이 항상 표시됩니다.
- 폰트는 [Galmuri9](https://galmuri.quiple.dev) (SIL OFL 1.1) 한글 픽셀 폰트를 사용합니다.

- 작물은 밭이 젖어 있는 동안 실시간으로 자랍니다. 마르기 전에 물을 주세요!
- **체력**은 동굴 전투에서만 깎입니다. 밖에서는 천천히 회복되고 요리로 즉시 회복.
  새벽 2시까지 안 자면 쓰러집니다.
- 집(E)에 들어가 침대에서 자면 다음 날이 되고 자동 저장됩니다.

## 연구 노트 (핵심 시스템)

`N` 키로 **할아버지의 연구 노트**를 펼칩니다. 처음엔 대부분 비어 있지만:
- 작물 첫 수확, 물고기 낚기, 광물 발견, 몬스터 처치, 요리 만들기,
  주민과 친해지기(호감도 50/100) 등 **새로운 발견마다 페이지가 채워집니다**
- 기록이 **50%를 넘으면 할아버지의 숨겨진 메모**가 하나씩 해금되어
  그가 평생 무엇을 연구했는지 조금씩 드러납니다
- 부지를 열 때마다 그 지역에 남은 **할아버지의 탐사 흔적**(장별 스토리)을 발견합니다
- 후반부, 모든 기록이 연결되면 **최후의 연금술**이 열립니다 — 그 결과는 직접 확인해 보세요
- 엔딩 후에도 자유롭게 계속 플레이할 수 있습니다

## 계절과 작물

계절은 28일마다 바뀌며(봄→여름→가을→겨울), 상점에서는 제철 씨앗만 팝니다.
계절이 바뀌면 제철이 아닌 작물은 시들어버리니 주의! (옥수수는 여름~가을 2계절)

작물은 **밭이 젖어 있는 동안 실시간으로 자랍니다** (게임 내 시간 기준).
손으로 물을 주면 6시간 동안 젖어 있고, 비 오는 날과 스프링클러 주변은
하루 종일 젖어 있습니다. 마르면 성장이 멈추니 자주 살펴주세요!

## 동굴 탐험

마을 북쪽의 **동굴 입구(E)**로 들어가면 층별로 생성되는 동굴이 나옵니다.
- `Space`로 몬스터를 공격! 닿으면 체력이 깎이니 조심하세요
- 몬스터 3종: 슬라임 / **박쥐**(2층~, 빠른 돌진) / **유령**(4층~, 벽 통과 추적)
  — 처치 기록은 상점 **도감 탭**에 쌓입니다
- 모은 광석으로 상점 강화 탭에서 호미/물뿌리개 **Lv3(3x3 범위)**,
  도끼/곡괭이 **Lv2(1타 채집 + 동굴 공격력 2배)** 강화가 가능합니다
- 광석 노드를 캐거나 슬라임을 잡아 **광석**을 모으고,
  한 층의 슬라임을 전멸시키면 **보상 상자**(광석/보석)와 다음 층 계단이 열립니다
- 층이 깊어질수록 강해지고 보상도 좋아집니다. 체력이 바닥나면 쫓겨납니다!

## 마을과 부지 확장

동쪽 길을 따라가면 **대형 마을**이 나옵니다 — 모든 거래는 마을에서!
- **잡화점**: 씨앗 구매·작물 판매 / **목장 상회**: 동물 입양 /
  **대장간**: 도구 강화 / **수산시장**: 도감·판매 / 광장의 **의뢰 게시판**
- `B` 단축키는 상점 건물이나 출하 상자 근처에서만 열립니다

맵은 7개 구역으로 나뉘고, **해금하지 않은 부지는 들어갈 수 없습니다**
(마을 가는 길은 항상 열려 있어요). 경계 표지판(E)에서 구입:
동쪽 들판 3,000G → 남쪽 들판 8,000G → 숲과 호수 15,000G →
강변 부지 20,000G(강 낚시) → 황금 평야 30,000G → 깊은 숲 50,000G(자원 밀집)

> ⚠️ 현재는 개발 버전이라 시작 자금이 1억G입니다 (모든 콘텐츠 확인용).
> 출시 밸런스에서는 500G로 돌아갑니다.

## 멀티플레이 (협동)

같은 네트워크(공유기/LAN)에서 함께 플레이할 수 있습니다.
1. 호스트: 타이틀 → **함께하기** → **방 만들기** (호스트의 농장/저장을 함께 사용)
2. 친구: **함께하기** → 호스트 IP 입력 → **참가**
- 돈/자원/씨앗은 농장 공동 소유, 기력은 각자
- 하루 넘기기(취침)와 저장은 호스트가 담당합니다
- 인터넷 멀리서 하려면 호스트가 포트(UDP 7777)를 열어야 합니다 (추후 스팀 로비로 개선 예정)
