# 🌾 교진 팜 (Kyojin Farm)

스타듀밸리 느낌의 **도트 그래픽 농장 시뮬레이션 게임**.
스팀 출시를 목표로 **Godot 4 엔진**으로 개발 중입니다.

핵심 루프: **밭 갈기 → 씨앗 심기 → 물 주기 → 수확 → 판매 → 취침(다음 날)**

## 프로젝트 구조

```
game/            # Godot 4 프로젝트 (메인 개발)
web-prototype/   # 초기 HTML5 프로토타입 (참고용, 브라우저에서 실행 가능)
ROADMAP.md       # 완성까지의 단계별 개발 계획
```

## 실행 방법 (Godot)

1. [Godot 4.4 이상](https://godotengine.org/download) 다운로드 (무료, 100MB 미만)
2. Godot 실행 → **가져오기(Import)** → 이 저장소의 `game/` 폴더 선택
3. 에디터가 열리면 **F5** (프로젝트 실행)

> 웹 프로토타입은 `web-prototype/index.html`을 브라우저로 열면 바로 실행됩니다.

> 처음 시작하면 **튜토리얼**이 화면 위 "다음 목표"로 기본 조작을 안내합니다.
> 처음엔 호미 하나뿐이지만, 목표를 달성할 때마다 **새 도구가 하나씩 해금**됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| `Space` / `Enter` | 현재 도구 사용 |
| `1` ~ `4` | 호미 / 물뿌리개 / 씨앗 / 수확 |
| `5` ~ `8` | 도끼 / 곡괭이 / 울타리 / 스프링클러 |
| `9` | 낚싯대 (물가에서 사용) |
| `Tab` | 씨앗 종류 바꾸기 |
| `E` | 상호작용 (집 앞: 취침 / 출하 상자: 판매) |
| `M` | 지도 열기 (집/마을/내 위치 확인) |
| `I` | 인벤토리 (보유 씨앗/수확물/자원) |
| `B` | 상점 열기 (구매/판매/업그레이드) |
| `F5` (게임 내) | 수동 저장 |
| `Esc` | 창 닫기 |

- 도끼로 나무를 베면 **목재**, 곡괭이로 돌을 캐면 **석재**를 얻습니다.
- 울타리(목재 1)와 스프링클러(목재 2+석재 2)를 설치할 수 있습니다.
  스프링클러는 매일 아침 주변 4칸에 물을 줍니다.
- 상점 강화 탭에서 호미/물뿌리개를 Lv2(전방 3칸)로 강화할 수 있습니다.
- 상점 동물 탭에서 닭/소를 입양하고, E로 쓰다듬어주면 다음 날 달걀/우유를 얻습니다.
- 낚싯대(9)로 물가에서 낚시: 입질(!)이 오면 Space → 타이밍 미니게임!
  잡은 물고기는 상점 도감 탭에 기록됩니다.
- 맵 동쪽 **마을**에 가면 NPC(민지, 철수)와 대화하고 선물해서 호감도를 쌓을 수 있습니다.
  호감도 50을 넘기면 NPC별 특전이 열립니다 — 민지: 씨앗 10% 할인 /
  철수: 낚시 판정 구간 25% 확대. **의뢰 게시판**에서 납품 의뢰도 받아 보세요.
- 화면 아래 **도트 아이콘 핫바**를 클릭하거나 숫자키로 도구를 고르고,
  타일 위에 뜨는 힌트(수확!/성장중/물주기!)를 따라가면 됩니다.
- 계절별 칩튠 BGM과 효과음이 나옵니다. 타이틀 화면 **설정**에서 음량과
  전체화면을 조절할 수 있고, 게임 중 `Esc`로 저장 후 타이틀로 돌아갈 수 있습니다.

- 물을 준 작물만 밤사이 자랍니다. 매일 물을 주세요!
- 도구를 쓰면 기력이 소모되고, 새벽 2시까지 안 자면 쓰러집니다.
- 취침하면 자동 저장됩니다.

## 계절과 작물

계절은 28일마다 바뀌며(봄→여름→가을→겨울), 상점에서는 제철 씨앗만 팝니다.
계절이 바뀌면 제철이 아닌 작물은 시들어버리니 주의! (옥수수는 여름~가을 2계절)
비 오는 날은 밭에 물이 저절로 뿌려집니다.

## 멀티플레이 (협동)

같은 네트워크(공유기/LAN)에서 함께 플레이할 수 있습니다.
1. 호스트: 타이틀 → **함께하기** → **방 만들기** (호스트의 농장/저장을 함께 사용)
2. 친구: **함께하기** → 호스트 IP 입력 → **참가**
- 돈/자원/씨앗은 농장 공동 소유, 기력은 각자
- 하루 넘기기(취침)와 저장은 호스트가 담당합니다
- 인터넷 멀리서 하려면 호스트가 포트(UDP 7777)를 열어야 합니다 (추후 스팀 로비로 개선 예정)
